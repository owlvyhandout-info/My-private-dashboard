คู่มือแก้ปัญหาทางเทคนิค

กดลิงก์เชิญ Google Classroom
แต่ระบบถามหา "รหัสชั้นเรียน"?

วิเคราะห์สาเหตุและวิธีแก้ไขแบบทีละขั้นตอน สำหรับนักเรียนทุกอุปกรณ์

⚠️

ประเด็นปัญหา

นักเรียนได้รับอีเมลเชิญจากครูผ่าน Google Classroom เมื่อกดลิงก์ในอีเมล ระบบไม่พาเข้าห้องเรียนโดยตรง แต่กลับแสดงหน้าขอให้กรอก "รหัสชั้นเรียน" ซึ่งนักเรียนไม่ทราบ ทำให้ไม่สามารถเข้าร่วมชั้นเรียนได้

1

การวินิจฉัยปัญหา (Diagnosis)

👤

บัญชีทับซ้อน (Multi-Account Conflict)

พบบ่อยที่สุด
อาการ บราวเซอร์หรือแอป Classroom มีการล็อกอินค้างไว้หลายบัญชี เช่น Gmail ส่วนตัว และอีเมลโรงเรียน
สาเหตุ เมื่อกดลิงก์ ระบบจะเรียกใช้ บัญชีหลัก (Default Account) ที่จดจำไว้ในเครื่อง ซึ่งมักเป็นบัญชีส่วนตัวที่ไม่มีสิทธิ์เข้าห้องเรียน ระบบจึงมองว่าเป็น "คนนอก" และร้องขอรหัสเพื่อยืนยันตัวตน
🔀

การเปิดผิดแอป (App Redirect Error)

พบบ่อย
อาการ กดลิงก์จากแอป Gmail หรือ LINE แล้วระบบเปิดผ่าน Web Browser แทนที่จะเปิดผ่านแอป Classroom โดยตรง
สาเหตุ บัญชีที่ล็อกอินอยู่ใน Web Browser ไม่ตรงกับบัญชีในแอป ทำให้สิทธิ์การเข้าถึงขัดแย้งกัน ระบบจึงไม่สามารถยืนยันตัวตนได้อัตโนมัติ
⏰

ลิงก์หมดอายุหรือถูกรีเซ็ต (Link Invalidation)

พบน้อย
อาการ ระบบแจ้งว่าลิงก์ไม่ถูกต้อง หรือหน้าแสดงข้อผิดพลาดและขอรหัสใหม่
สาเหตุ ครูผู้สอนอาจ "รีเซ็ตรหัสชั้นเรียน" หรือ "ปิดการเข้าร่วมผ่านลิงก์" ไปแล้วหลังจากส่งอีเมลเชิญ ทำให้ลิงก์เดิมใช้งานไม่ได้อีกต่อไป
เพิ่มเติม บางครั้งเกิดจากการคัดลอกลิงก์ผิดพลาด เช่น มีช่องว่างหรืออักขระพิเศษปนมา หรือลิงก์ถูกตัดให้สั้นลงโดยแอปรับส่งข้อความ
2

วิธีแก้ไขทีละขั้นตอน (Solutions)

1

สลับบัญชีที่หน้าจอขอรหัส

📱 มือถือ 💻 PC
▾

วิธีนี้แก้ปัญหาได้ตรงจุดที่สุด โดยไม่ต้องปิดหน้าต่างหรือเริ่มใหม่

  1. เมื่อหน้าจอแสดงช่องให้กรอกรหัสชั้นเรียน อย่าเพิ่งกรอกอะไร
  2. สังเกตที่ มุมขวาบนของหน้าจอ จะเห็นรูปวงกลมโปรไฟล์ (ตัวอักษรหรือรูปภาพ)
  3. แตะ/คลิกที่รูปโปรไฟล์นั้น ระบบจะแสดงรายชื่ออีเมลที่ล็อกอินค้างไว้ทั้งหมด
  4. ตรวจสอบว่าบัญชีที่ใช้งานอยู่ (ตัวหนาหรืออยู่บนสุด) ใช่ อีเมลโรงเรียน หรือไม่
  5. หากไม่ใช่ ให้เลือกอีเมลโรงเรียน ระบบจะรีเฟรชและพาเข้าชั้นเรียนทันทีโดยไม่ต้องกรอกรหัส
💡 หมายเหตุ หากยังไม่เห็นอีเมลโรงเรียนในรายการ ให้เลือก "ใช้บัญชีอื่น" (Use another account) แล้วล็อกอินด้วยอีเมลโรงเรียนให้สำเร็จก่อน
2

ใช้หน้าต่าง Incognito (Private)

💻 PC / Mac
▾

วิธีนี้ตัดปัญหาบัญชีซ้ำซ้อนได้ 100% เพราะหน้าต่าง Incognito ไม่จดจำบัญชีเดิมใดๆ

  1. คลิกขวาที่ลิงก์เชิญในอีเมล → เลือก "คัดลอกที่อยู่ลิงก์" (Copy link address)
  2. เปิด Chrome ขึ้นมา แล้วกด Ctrl + Shift + N บน Windows / ⌘ + Shift + N บน Mac เพื่อเปิดหน้าต่าง Incognito (สีเข้ม)
  3. วาง URL ลิงก์ในช่องที่อยู่ แล้วกด Enter
  4. ระบบจะบังคับให้ล็อกอินใหม่ — ใส่เฉพาะ อีเมลโรงเรียน และรหัสผ่านเท่านั้น
  5. คุณจะเข้าห้องเรียนได้ทันที
สำหรับ Safari (Mac) กด ⌘ + Shift + N เพื่อเปิด Private Window แล้วทำขั้นตอนเดียวกัน
3

เพิ่มบัญชีโรงเรียนในแอป Classroom

📱 iPhone / iPad 🤖 Android
▾

แนะนำเมื่อยังไม่เคยล็อกอินด้วยอีเมลโรงเรียนในแอปมาก่อน

  1. เปิดแอป Google Classroom บนมือถือ
  2. แตะที่รูปโปรไฟล์มุมขวาบน
  3. เลือก "เพิ่มบัญชีอื่น" (Add another account)
  4. ล็อกอินด้วยอีเมลโรงเรียนให้สำเร็จ
  5. กลับไปที่อีเมลเชิญแล้วกดลิงก์อีกครั้ง ระบบจะถามว่าต้องการใช้บัญชีใด — เลือก บัญชีโรงเรียน
💡 เคล็ดลับ สลับบัญชีได้ง่ายๆ โดยแตะที่ชื่อบัญชีในหน้าหลักของแอป Classroom แล้วเลือกบัญชีที่ต้องการ
4

แกะรหัสจาก URL แล้วกรอกเอง

📱 มือถือ 💻 PC
▾

ใช้เมื่อลิงก์นำทางไม่ได้ แต่ URL ยังสมบูรณ์ดีอยู่

  1. คัดลอก URL ของลิงก์เชิญ เช่น:
    https://classroom.google.com/c/MTIzNDU2?cjc=abc1234
  2. สังเกตตัวอักษรหลัง cjc= นั่นคือ รหัสชั้นเรียน (ในตัวอย่างคือ abc1234)
  3. เปิดแอป Classroom → กดเครื่องหมาย + มุมขวาบน → เลือก "เข้าร่วมชั้นเรียน" (Join class)
  4. กรอกรหัสที่ได้จาก URL แล้วกด เข้าร่วม
⚠️ ข้อควรระวัง ต้องแน่ใจว่าล็อกอินด้วยบัญชีโรงเรียนในแอปก่อน มิฉะนั้นจะยังเข้าไม่ได้แม้จะมีรหัสถูกต้อง
5

ติดต่อครูเพื่อขอลิงก์หรือรหัสใหม่

🔄 กรณีสุดท้าย
▾

หากลองทุกวิธีข้างต้นแล้วยังเข้าไม่ได้ สาเหตุอาจอยู่ที่ลิงก์ถูกรีเซ็ตจากฝั่งครู

  1. แจ้งครูว่ากดลิงก์แล้ว "ระบบถามหารหัสชั้นเรียน" และไม่สามารถเข้าได้
  2. ขอให้ครูส่ง รหัสชั้นเรียน (Class Code) โดยตรง (ตัวอักษร 5–7 ตัว)
  3. หรือขอให้ครูส่ง ลิงก์เชิญใหม่ (ครูสามารถสร้างลิงก์ใหม่ได้จากเมนูการตั้งค่าชั้นเรียน)
  4. นำรหัสที่ได้รับมากรอกในแอป Classroom → + → เข้าร่วมชั้นเรียน

🗺️ ตารางตัดสินใจ — ควรใช้วิธีใด?

มีหลายบัญชีในเครื่อง และใช้ PC หรือมือถือ → ✅ วิธีที่ 1 (สลับบัญชีในหน้าเดิม)
ใช้ PC และต้องการวิธีที่แน่นอนที่สุด → ✅ วิธีที่ 2 (Incognito Mode)
ใช้มือถือ และยังไม่เคยล็อกอินด้วยบัญชีโรงเรียนในแอป → ✅ วิธีที่ 3 (เพิ่มบัญชีในแอป)
ลิงก์ไม่นำทาง แต่สามารถคัดลอก URL ได้ → ✅ วิธีที่ 4 (แกะรหัสจาก URL)
ลองทุกวิธีแล้วยังไม่ได้ → ✅ วิธีที่ 5 (ติดต่อครู)
🛡️

คำแนะนำเพื่อป้องกันปัญหาในระยะยาว

  • ตั้งค่าให้ อีเมลโรงเรียน เป็นบัญชีหลัก (Default) บนอุปกรณ์ที่ใช้เรียน
  • ออกจากระบบบัญชีส่วนตัวชั่วคราวก่อนกดลิงก์เชิญชั้นเรียนใหม่ในครั้งแรก
  • หากใช้มือถือ ให้กดลิงก์จากแอป Gmail (ไม่ใช่แอป LINE หรือ Messages) เพื่อหลีกเลี่ยงปัญหาการเปิดผิดแอป
  • หลังเข้าร่วมชั้นเรียนสำเร็จแล้ว Classroom จะจดจำห้องเรียนไว้โดยอัตโนมัติ ไม่จำเป็นต้องกดลิงก์เชิญซ้ำอีก
  • บันทึก รหัสชั้นเรียน เก็บไว้เสมอ เผื่อต้องเข้าร่วมด้วยตนเองในภายหลัง
