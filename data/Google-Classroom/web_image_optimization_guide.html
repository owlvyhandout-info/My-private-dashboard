🌐 Web Image Optimization & Automation

คู่มือการตั้งค่าขนาดรูปภาพ & บีบอัดไฟล์สำหรับหน้าเว็บ

หลักการสำคัญไม่ใช่แค่ "ขนาดภาพ" (Dimensions) แต่คือ "ขนาดไฟล์" (File Size) เพื่อให้หน้าเว็บโหลดได้อย่างรวดเร็ว ไม่หน่วง เพิ่มประสิทธิภาพให้กับ SEO และประสบการณ์ที่ดีของผู้ใช้งาน

1. เกณฑ์มาตรฐานของรูปภาพบนเว็บไซต์

เป้าหมายสูงสุดคือ รูปภาพเล็กพอที่จะโหลดไว แต่ยังคงความคมชัดที่ตาแยกไม่ออก

🖼️ ไฟล์แบนเนอร์ (Full Banner)

ขนาดไฟล์: ไม่เกิน 200KB - 500KB

มิติที่แนะนำ: กว้าง 1920px (หรือ 1600px) × สูง 400px - 600px

📝 รูปประกอบเนื้อหาทั่วไป

ขนาดไฟล์: ไม่เกิน 50KB - 150KB

มิติที่แนะนำ: ความกว้างไม่เกิน 800px - 1000px (ตามคอลัมน์)

⚡ ฟอร์แมตไฟล์ยอดนิยม

WebP: แนะนำที่สุด เล็ก คมชัดสูง

JPEG: เหมาะกับภาพถ่ายรายละเอียดสีเยอะ

PNG: เหมาะกับรูปที่มีพื้นหลังโปร่งใส

💡 เคล็ดลับเพิ่มเติม: หากรูปภาพมีขนาดเกิน 500KB ควรส่งผ่านเครื่องมือบีบอัด (Compression) เช่น TinyPNG หรือ Squoosh.app เสมอ

⚠️ ข้อควรระวังเมื่ออัปโหลดขึ้น GitHub

แม้ GitHub จะรองรับไฟล์ได้สูงสุด 100MB แต่ถ้าเป็นการแสดงผลบน GitHub Pages หรือเว็บไซต์ทั่วไป:

  • ปัญหาเว็บโหลดช้า: ไฟล์ที่ใหญ่เกินไปจะทำให้ผู้ใช้งานรู้สึกว่าเว็บค้าง ส่งผลเสียรุนแรงต่อ SEO และ UX
  • การตั้งชื่อไฟล์: ควรใช้ ตัวพิมพ์เล็กทั้งหมด ไม่มีเว้นวรรค และไม่มีอักขระพิเศษ เช่น ปรับจาก Desert Banner 01!.png เป็น desert-banner.webp เพื่อการเข้าถึงที่เสถียรในทุกระบบ

🛠️ คู่มือทีละขั้นตอน: บีบอัดรูปภาพด้วย XnConvert

เครื่องมือทรงประสิทธิภาพในการย่อและบีบอัดไฟล์ภาพจำนวนมากพร้อมๆ กัน เพื่อคุมขนาดให้อยู่ในช่วง 200KB - 500KB

1

เพิ่มไฟล์รูปภาพ (Input)

เปิดโปรแกรม XnConvert ไปที่แถบ Input → กดปุ่ม Add files แล้วเลือกรูปภาพแบนเนอร์ที่คุณต้องการจัดการเข้ามาในระบบ

2

ตั้งค่าปรับมิติภาพ (Actions)

ไปที่แถบ Actions → กด Add action > Image > Resize

  • ตั้งค่า Width (ความกว้าง): 1920 px (หรือตามความกว้างสูงสุดของหน้าเว็บคุณ)
  • ตั้งค่า Height (ความสูง): ปล่อยเป็น Automatic เพื่อรักษาอัตราส่วนภาพดั้งเดิมไว้ ไม่ให้ภาพบิดเบี้ยว
3

ตั้งค่าการบีบอัดควบคุมขนาดไฟล์ (Output)

ไปที่แถบ Output เพื่อกำหนดลักษณะไฟล์ปลายทาง:

  • Format: แนะนำให้เลือก WebP (บีบอัดดีที่สุด) หรือ JPG จากนั้นกดปุ่ม Settings ข้างๆ ช่องเลือก Format
  • ถ้าเลือก JPG: ปรับค่า Quality ลงมาอยู่ระหว่าง 60 - 80
  • ถ้าเลือก WebP: ปรับค่า Quality ลงมาอยู่ระหว่าง 60 - 75
📌 เทคนิคการล็อคขนาดไฟล์ไม่ให้เกิน 500KB: ให้เริ่มต้นทดสอบที่ Quality 70 แล้วกด Convert ดูผลลัพธ์ หากขนาดไฟล์ยังเกิน 500KB ให้กลับมาลดค่า Quality ลงทีละ 5 (เช่น 65, 60) แล้วลองใหม่อีกครั้ง
4

ดำเนินการแปลงไฟล์ (Convert)

เลือก Output folder (โฟลเดอร์ปลายทางที่ต้องการบันทึกไฟล์) จากนั้นตรวจสอบชื่อไฟล์ที่ตั้งไว้ (แนะนำตัวพิมพ์เล็กและคั่นด้วยขีดกลาง) → กดปุ่ม Convert บริเวณมุมล่างขวา

💡 แก้ไขปัญหาภาพเบลอ: หากลด Quality จนถึง 60 แล้วแต่ขนาดไฟล์ยังเกิน 500KB แสดงว่าภาพต้นฉบับละเอียดเกินไป (เช่น 4K) แนะนำให้กลับไปที่ขั้นตอนที่ 2 แล้วปรับแก้ Width (Resize) ลดลงเหลือ 1600px จะช่วยลดขนาดไฟล์ได้อย่างมีประสิทธิภาพสูงสุดโดยไม่สูญเสียความคมชัด
