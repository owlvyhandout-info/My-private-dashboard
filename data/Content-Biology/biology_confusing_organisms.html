🌀 ตอนที่ 1 — ชื่อคล้ายกัน สับสนกันบ่อย
🌊 Spirulina vs Spirogyra — สาหร่ายสองตัวที่ไม่เหมือนกันเลย
🧫
Spirulina
สาหร่ายเกลียวทอง
แบคทีเรียเซลล์เดียว
  • อาณาจักร Bacteria
  • เซลล์ โพรคาริโอต
  • คลอโรพลาสต์ ✗ ไม่มี
  • นิวเคลียส ✗ ไม่มี
  • ประโยชน์ อาหารเสริม โปรตีนสูง
🌿
Spirogyra
ตะไคร่น้ำ / สาหร่ายเส้นด้าย
โพรทิสต์หลายเซลล์
  • อาณาจักร Protista
  • เซลล์ ยูคาริโอต
  • คลอโรพลาสต์ ✓ มี (เกลียว)
  • นิวเคลียส ✓ มี
  • ลักษณะ เส้นใยเรียงต่อกัน

🔑 จำง่าย: Spirogyra → gyrate = หมุน → คลอโรพลาสต์หมุนเป็นเกลียว → สาหร่ายจริง (โพรทิสต์)
Spirulina → ขายในร้านขายยา → เป็นแบคทีเรียที่คนกิน ❌ ไม่มีคลอโรพลาสต์

🌱 จอก / แหน / แหนเป็ด (พืชดอก) vs จอกหูหนู / แหนแดง (เฟิร์น)
🪷
จอก
พืชดอก
  • ท่อลำเลียง ✓
  • เมล็ด ✓
  • ดอก ✓
  • ลักษณะ ใบกลม ลอยน้ำ
🍀
แหน / แหนเป็ด
พืชดอก
  • ท่อลำเลียง ✓
  • เมล็ด ✓
  • ดอก ✓ (เล็กมาก)
  • ลักษณะ ต้นจิ๋ว ลอยน้ำ
🐭
จอกหูหนู
เฟิร์น
  • ท่อลำเลียง ✓
  • เมล็ด ✗
  • สืบพันธุ์ สปอร์
  • ลักษณะ ใบมีขนคล้ายหูหนู
🍂
แหนแดง (Azolla)
เฟิร์น
  • ท่อลำเลียง ✓
  • เมล็ด ✗
  • ประโยชน์ ปุ๋ยพืชสด
  • พิเศษ ตรึง N₂ ร่วมกับแบคทีเรีย

🔑 ถ้าชื่อมี "หูหนู" หรือ "แดง" = เฟิร์น ไม่ใช่พืชดอก! แหนเป็ดดูเหมือนเล็กจนนึกว่าไม่มีดอก แต่มีดอกจริง (แค่เล็กมาก)

🌈 "สาหร่าย" — ชื่อเดียวกัน แต่อยู่คนละอาณาจักร!
💙
สาหร่ายสีเขียวแกมน้ำเงิน
Cyanobacteria
แบคทีเรียเซลล์เดียว
  • เซลล์ โพรคาริโอต
  • คลอโรพลาสต์ ✗
  • ตัวอย่าง Spirulina, Anabaena
🟢
สาหร่ายสีเขียว
Chlorophyta
โพรทิสต์
  • เซลล์ ยูคาริโอต
  • คลอโรพลาสต์ ✓
  • ตัวอย่าง Spirogyra, Chlorella
🔴
สาหร่ายสีแดง/น้ำตาล
Rhodophyta / Phaeophyta
โพรทิสต์
  • เซลล์ ยูคาริโอต
  • คลอโรพลาสต์ ✓
  • ตัวอย่าง สาหร่ายทะเลกินได้
🌾
สาหร่ายหางกระรอก / ข้าวเหนียว
พืชน้ำ
พืชดอก
  • ท่อลำเลียง ✓
  • ดอก ✓
  • ราก ✓

🔑 ชื่อมี "แกมน้ำเงิน" = แบคทีเรีย เสมอ | "หางกระรอก / ข้าวเหนียว" = พืชดอก มีดอกจริง | สาหร่ายทะเลในร้านอาหารญี่ปุ่น = โพรทิสต์

🌲 "สน" — บางต้นเมล็ดเปลือย บางต้นพืชดอก!
🌲
สนเขา / สนสองใบ / สนสามใบ
Pinaceae
เมล็ดเปลือย
  • กลุ่ม Gymnosperm
  • เมล็ด เปลือย บนเกล็ดโคน
  • โคนสน ✓ มีชัดเจน
  • ใบ เป็นเข็ม เป็นมัด
🌴
สนทะเล / สนปฏิพัทธิ์
Casuarinaceae
พืชดอก
  • กลุ่ม Angiosperm
  • เมล็ด มีผลห่อหุ้ม
  • โคนสน ✗ ไม่มี
  • ลักษณะ กิ่งเรียว คล้ายเข็ม แต่จริงๆ คือกิ่ง

🔑 สน + ทะเล / ปฏิพัทธิ์ = ดูสวยงามชายทะเล → พืชดอก (หลอกตา!)
สนสอง/สามใบ = นับใบเป็นมัด + มีโคนสนจริง = Gymnosperm

🌿 ตอนที่ 2 — กลุ่มพืชไม่มีดอก
🍄 มอส / ลิเวอร์เวิร์ต / ฮอร์นเวิร์ต vs เฟิร์น — ต่างกันที่ท่อลำเลียง
🌱
มอส (Moss)
Bryophyta
  • ท่อลำเลียง ✗
  • ราก ✗ (ไรซอยด์)
  • เมล็ด ✗ สปอร์
  • ลักษณะ ต้นตั้งตรง ใบเล็ก
🫁
ลิเวอร์เวิร์ต
Bryophyta
  • ท่อลำเลียง ✗
  • ราก ✗
  • เมล็ด ✗ สปอร์
  • ลักษณะ แบนราบ คล้ายตับ
🪺
ฮอร์นเวิร์ต
Bryophyta
  • ท่อลำเลียง ✗
  • ราก ✗
  • เมล็ด ✗ สปอร์
  • ลักษณะ มีแกนกลางคล้ายแตร
🌿
เฟิร์น
Pteridophyta
  • ท่อลำเลียง ✓
  • ราก ✓
  • เมล็ด ✗ สปอร์
  • ลักษณะ ใบใหญ่ สปอร์ใต้ใบ

🔑 ไบรโอไฟต์ (มอส+ลิเวอร์เวิร์ต+ฮอร์นเวิร์ต) = ❌ท่อลำเลียง ❌ราก ❌เมล็ด
เฟิร์น = ✅ท่อลำเลียง ✅ราก ❌เมล็ด (อยู่ "กลาง" ระหว่างไบรโอไฟต์กับพืชมีเมล็ด)

🦠 ตอนที่ 3 — โพรทิสต์ที่คนสับสน
🔬 ยูกลีนา vs พารามีเซียม vs อะมีบา — โพรทิสต์ต่างนิสัย
👁️
ยูกลีนา
Euglena
โพรทิสต์
  • เคลื่อนที่ แฟลกเจลลา (หาง)
  • สังเคราะห์แสง ✓ ได้
  • กินอาหาร ✓ ได้ด้วย
  • พิเศษ มีจุดตาแดง
  • จำพวก Mixotroph
🥿
พารามีเซียม
Paramecium
โพรทิสต์
  • เคลื่อนที่ ซิเลีย (ขนรอบตัว)
  • สังเคราะห์แสง ✗
  • กินอาหาร กินแบคทีเรีย
  • ลักษณะ คล้ายรองเท้าแตะ
🫧
อะมีบา
Amoeba
โพรทิสต์
  • เคลื่อนที่ ซูโดโพเดีย (เท้าเทียม)
  • สังเคราะห์แสง ✗
  • กินอาหาร ล้อมจับเหยื่อ
  • รูปร่าง เปลี่ยนได้ตลอด

🔑 ยูกลีนา = ทำได้ทั้งสองอย่าง (สังเคราะห์แสง + กินอาหาร) จึงไม่ใช่ทั้งพืชและสัตว์ → จัดเป็น โพรทิสต์ | Anabaena ≠ Amoeba — Anabaena คือแบคทีเรียตรึงไนโตรเจน!

🍄 ตอนที่ 4 — เห็ด รา ไลเคน ไวรัส
🍄 เห็ด vs รา vs ไลเคน vs ไวรัส — ไม่ใช่พืชทั้งหมด!
🍄
เห็ด
Fungi
  • เซลล์ ยูคาริโอต
  • สังเคราะห์แสง ✗
  • ลักษณะ มีดอกเห็ด (fruiting body)
  • สืบพันธุ์ สปอร์
🦠
รา
Fungi
  • เซลล์ ยูคาริโอต
  • สังเคราะห์แสง ✗
  • ลักษณะ ไม่มีดอกเห็ด
  • สืบพันธุ์ สปอร์
🪨
ไลเคน
Fungi+สาหร่าย
  • คือ ราบวกสาหร่ายอยู่ด้วยกัน
  • ความสัมพันธ์ Symbiosis
  • พิเศษ บอกค่า pH อากาศ
💉
ไวรัส
ไม่ใช่เซลล์
  • เซลล์ ✗ ไม่มี
  • สืบพันธุ์ ต้องอาศัยเซลล์โฮสต์
  • ลักษณะ DNA/RNA + โปรตีนห่อหุ้ม
  • มีชีวิต? ถกเถียง!

🔑 ไลเคน ≠ สิ่งมีชีวิตชนิดเดียว! = รา + สาหร่าย อยู่ร่วมกัน | ไวรัส = ไม่มีเซลล์ → จัดอาณาจักรไม่ได้เลย (บางคนไม่นับว่ามีชีวิต)

📋 สรุปรวม — ตารางเปรียบเทียบ
📊 ตารางสรุปหลักการจำแนก
กลุ่ม ท่อลำเลียง เมล็ด ผลห่อเมล็ด เซลล์ ตัวอย่าง
🦠 แบคทีเรีย✗✗✗โพรคาริโอตSpirulina, Anabaena
🔬 โพรทิสต์✗✗✗ยูคาริโอตสาหร่ายสีเขียว, ยูกลีนา
🍄 ฟังไจ✗✗✗ยูคาริโอตเห็ด, รา
🌱 ไบรโอไฟต์✗✗✗ยูคาริโอตมอส, ลิเวอร์เวิร์ต
🌿 เฟิร์น✓✗✗ยูคาริโอตกูด, แหนแดง, จอกหูหนู
🌲 Gymnosperm✓✓✗ เปลือยยูคาริโอตสนสองใบ, สนสามใบ
🌸 Angiosperm✓✓✓ มีผลยูคาริโอตสนทะเล, แหน, จอก, ข้าว
💡 เคล็ดลับจำ
💡 5 หลักคิด จำแนกสิ่งมีชีวิตให้ถูก
1️⃣
ชื่อไทยหลอกได้! "สาหร่าย" และ "สน" มีได้หลายอาณาจักร ต้องดูโครงสร้างจริง ไม่ใช่ชื่อ
2️⃣
มีท่อลำเลียงไหม? ไม่มี = ไบรโอไฟต์ (หรือต่ำกว่า) | มี = เฟิร์นหรือสูงกว่า
3️⃣
มีเมล็ดไหม? ไม่มี = เฟิร์นหรือต่ำกว่า | มี = พืชเมล็ด (Gymnosperm หรือ Angiosperm)
4️⃣
เมล็ดเปลือยหรือมีผล? เปลือย = Gymnosperm (สนเขา) | ห่อด้วยผล = Angiosperm (สนทะเล)
5️⃣
โพรคาริโอต = แบคทีเรียเท่านั้น! ทุกสิ่งมีชีวิตอื่นล้วนเป็น ยูคาริโอต
