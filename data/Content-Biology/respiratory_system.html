1. ภาพรวมระบบหายใจ

ระบบหายใจทำหน้าที่หลัก 2 อย่าง คือ นำแก๊สออกซิเจน (O₂) เข้าสู่ร่างกาย เพื่อใช้ในการสลายสารอาหารให้เป็นพลังงาน และกำจัดแก๊สคาร์บอนไดออกไซด์ (CO₂) ซึ่งเป็นของเสียจากกระบวนการนั้นออกจากร่างกาย

→
ถุงลมปอด (Alveolus)
→
หลอดเลือดฝอย

🔑 ใจความสำคัญ โครงสร้างที่ทำหน้าที่แลกเปลี่ยนแก๊สทุกชนิด (ถุงลมปอด เหงือกปลา ผิวหนังไส้เดือน) มีลักษณะร่วมกันคือ ผนังบางและชุ่มชื้นเสมอ (เพื่อให้แก๊สละลายน้ำก่อนแพร่ผ่านได้) และ มีพื้นที่ผิวมากเมื่อเทียบกับปริมาตร ส่วน "มีเส้นเลือดฝอยมาเลี้ยง" และ "แลกเปลี่ยนได้ทั้งบนบก-ในน้ำ" ไม่ใช่คุณสมบัติร่วมพื้นฐาน เพราะแมลงใช้ระบบท่อลมนำแก๊สเข้าเซลล์โดยตรงโดยไม่ผ่านเลือด และสิ่งมีชีวิตแต่ละชนิดมักแลกเปลี่ยนแก๊สได้ดีในสภาพแวดล้อมเดียวเท่านั้น
Part 1

2. ปอดกับหัวใจ: การเชื่อมโยงการไหลเวียนเลือด

หัวใจและปอดทำงานร่วมกันผ่าน วงจรไหลเวียนเลือดแบบปิด ซึ่งแบ่งเป็น 2 วงจรย่อย:

🫀 วงจรปอด (Pulmonary circulation)

หัวใจ (ห้องล่างขวา) → หลอดเลือดแดงปอด (นำเลือดที่มี CO₂ สูง) → ถุงลมปอด (แลกเปลี่ยนแก๊ส) → หลอดเลือดดำปอด (นำเลือดที่มี O₂ สูง) → หัวใจ (ห้องบนซ้าย)

🧍 วงจรทั่วร่างกาย (Systemic circulation)

หัวใจ (ห้องล่างซ้าย) → หลอดเลือดเอออร์ตา (นำเลือดที่มี O₂ สูง) → เซลล์เนื้อเยื่อ (แลกเปลี่ยนแก๊ส) → หลอดเลือดเวนาคาวา (นำเลือดที่มี CO₂ สูง) → หัวใจ (ห้องบนขวา)

ลำดับการหมุนเวียนเลือดในร่างกาย (โจทย์พบบ่อย): หัวใจ → หลอดเลือดแดง → หลอดเลือดฝอย → หลอดเลือดดำ → ปอด → (กลับเข้าหัวใจ) การแลกเปลี่ยนแก๊สจะเกิดขึ้นเฉพาะที่ หลอดเลือดฝอย เท่านั้น ไม่ว่าจะเป็นที่ปอดหรือที่เนื้อเยื่อ เพราะผนังหลอดเลือดฝอยบางเพียงชั้นเดียว

💡 เทคนิคทำโจทย์ เมื่อโจทย์ถามหา "ตำแหน่งที่มี CO₂ สูงที่สุด" ให้มองหาตำแหน่งก่อนเข้าปอด (หลอดเลือดแดงปอด) และเมื่อถามหา "ตำแหน่งที่มี O₂ สูงที่สุด" ให้มองหาตำแหน่งหลังออกจากปอด (หลอดเลือดดำปอด) — สองตำแหน่งนี้เป็นข้อยกเว้นที่ชื่อหลอดเลือด "แดง-ดำ" สลับกับปริมาณแก๊สที่คุ้นเคย

3. การแลกเปลี่ยนแก๊สระหว่างหลอดเลือดฝอยกับถุงลมปอด

การแลกเปลี่ยนแก๊สเกิดจาก การแพร่ (diffusion) ของแก๊สจากบริเวณที่มีความเข้มข้น (ความดันย่อย) สูง ไปยังบริเวณที่มีความเข้มข้นต่ำกว่า โดยไม่ใช้พลังงานจากเซลล์ (passive transport)

ตำแหน่งแก๊สที่แพร่เข้าถุงลม/ปอดแก๊สที่แพร่เข้าเลือด
ถุงลมปอด ↔ หลอดเลือดฝอยCO₂ (จากเลือด → ถุงลม)O₂ (จากถุงลม → เลือด)
เซลล์เนื้อเยื่อ ↔ หลอดเลือดฝอยO₂ (จากเลือด → เซลล์)CO₂ (จากเซลล์ → เลือด)

ทิศทางตรงข้ามกันนี้เกิดเพราะที่ถุงลม อากาศที่หายใจเข้าใหม่มี O₂ เข้มข้นสูงกว่าในเลือด ส่วนที่เซลล์เนื้อเยื่อ เซลล์ใช้ O₂ ไปสลายพลังงานตลอดเวลาทำให้ O₂ ในเซลล์ต่ำกว่าในเลือดเสมอ

โรคถุงลมโป่งพอง (Emphysema)

เมื่อผนังถุงลมถูกทำลายและรวมตัวกันเป็นถุงลมขนาดใหญ่ พื้นที่ผิวรวมทั้งหมดจะลดลง แม้ปริมาตรอากาศที่หายใจเข้าเท่าเดิม แต่ประสิทธิภาพการแลกเปลี่ยนแก๊สลดลง ทำให้ O₂ เข้าสู่เลือดได้น้อยลงและเกิดภาวะหายใจลำบาก

⚠️ เข้าใจผิดบ่อย ถุงลมและหลอดเลือดฝอยมีผนังหลายชั้นเพื่อความแข็งแรง
✓ ที่จริงผนังถุงลมและหลอดเลือดฝอยเป็นเซลล์ชั้นเดียว (เยื่อบาง) เพื่อให้แก๊สแพร่ผ่านได้ง่ายและรวดเร็วที่สุด
Part 3

4. การนำส่งแก๊สไปยังเนื้อเยื่อ

เมื่อ O₂ แพร่เข้าสู่หลอดเลือดฝอยที่ถุงลมแล้ว จะถูกลำเลียงไปยังเซลล์ทั่วร่างกายได้ 2 รูปแบบ:

1) ละลายในน้ำเลือด

O₂ ประมาณ 3–5% ละลายในพลาสมาโดยตรง (Dissolved O₂)

2) จับกับฮีโมโกลบิน

O₂ ส่วนใหญ่จับกับฮีโมโกลบิน (Hb) ในเม็ดเลือดแดง กลายเป็น Oxyhemoglobin (HbO₂) ซึ่งขนส่ง O₂ ได้มากกว่าการละลายในน้ำเลือดถึงประมาณ 65 เท่า

ตำแหน่งที่ O₂ จับกับฮีโมโกลบินคือตำแหน่งที่มี ธาตุเหล็ก (Fe) อยู่ในโมเลกุลฮีโมโกลบิน ดังนั้นหากร่างกายขาดธาตุเหล็ก จะสร้างฮีโมโกลบินได้ไม่เพียงพอ ส่งผลให้การขนส่ง O₂ บกพร่อง (เกิดภาวะโลหิตจาง) แม้ระบบหายใจ (ปอด) เองจะปกติดีก็ตาม

🔑 ใจความสำคัญ เมื่อเลือดไหลผ่านเซลล์เนื้อเยื่อที่ขาด O₂ ฮีโมโกลบินจะปล่อย O₂ ออกมาให้เซลล์ใช้ในกระบวนการหายใจระดับเซลล์ (Cellular respiration) เพื่อสลายสารอาหารให้เป็นพลังงาน ส่วน CO₂ ที่เกิดขึ้นจะแพร่กลับเข้าสู่เลือดเพื่อถูกส่งกลับไปกำจัดที่ปอด

การหายใจระดับเซลล์ vs การเผาไหม้

การหายใจระดับเซลล์การเผาไหม้
สารตั้งต้นสารอาหาร + O₂เชื้อเพลิง + O₂
ผลิตภัณฑ์CO₂ + น้ำ + พลังงานCO₂ + น้ำ + พลังงาน
อุณหภูมิที่เกิดปฏิกิริยาอุณหภูมิร่างกาย (ต่ำ)อุณหภูมิสูง
ลักษณะการปลดปล่อยพลังงานหลายขั้นตอน ปลดปล่อยทีละน้อยรวดเร็วในครั้งเดียว
⚠️ เข้าใจผิดบ่อย การแลกเปลี่ยนแก๊สที่ถุงลมปอดคือ "การหายใจระดับเซลล์"
✓ การแลกเปลี่ยนแก๊สที่ถุงลม/เนื้อเยื่อเป็นเพียงการแพร่แก๊สทางกายภาพ ส่วน "การหายใจระดับเซลล์" หมายถึงกระบวนการทางเคมีภายในเซลล์ (ที่ไมโทคอนเดรีย) ที่ใช้ O₂ สลายสารอาหารให้เป็นพลังงาน ATP

5. กะบังลมกับอวัยวะที่เกี่ยวข้อง

การหายใจเข้า-ออกเกิดจากการเปลี่ยนแปลงปริมาตรช่องอก ซึ่งควบคุมโดยการทำงานร่วมกันของ กะบังลม (Diaphragm) และ กล้ามเนื้อยึดกระดูกซี่โครง โดยทั้งสองเคลื่อนที่ใน "ทิศทางตรงกันข้าม" เสมอ:

อวัยวะขณะหายใจเข้า (Inhalation)ขณะหายใจออก (Exhalation)
กะบังลมหดตัว → เคลื่อนต่ำลง (แบนราบ)คลายตัว → โค้งสูงขึ้น (กลับตำแหน่งเดิม)
กระดูกซี่โครงยกตัวสูงขึ้นเลื่อนต่ำลง (กลับตำแหน่งเดิม)
ปริมาตรช่องอกเพิ่มขึ้นลดลง
ความดันในช่องอกลดลง (ต่ำกว่าบรรยากาศ)เพิ่มขึ้น (สูงกว่าบรรยากาศ)
ทิศทางการไหลของอากาศไหลเข้าสู่ปอดไหลออกจากปอด
💡 เทคนิคจำ "กะบังลมหดตัว-ต่ำลง = หายใจเข้า" ส่วนกระดูกซี่โครงกับกะบังลมสวนทางกันเสมอ: เมื่อกะบังลมลดต่ำ กระดูกซี่โครงจะยกสูงขึ้น ทั้งสองช่วยกันขยายปริมาตรช่องอกไปพร้อมกัน (ไม่ใช่แข่งกัน)

แบบจำลองการหายใจ (Bell-jar model)

แบบจำลองขวดโหลที่มีแผ่นยางด้านล่างและลูกโป่งด้านใน ใช้แสดงทิศทางการไหลของอากาศเท่านั้น เมื่อดึงแผ่นยางลง (จำลองกะบังลมหดตัว) ปริมาตรในขวดเพิ่ม ความดันลด ลูกโป่งจะพองตัว (จำลองอากาศเข้าปอด)

⚠️ เข้าใจผิดบ่อย แบบจำลองนี้บอกได้ว่า O₂ กำลังเข้าไปในลูกโป่ง
✓ แบบจำลองบอกได้เพียงว่า "อากาศ" ไหลเข้า/ออกทิศทางใด แต่ไม่สามารถระบุชนิดของแก๊ส (O₂ หรือ CO₂) ที่กำลังเคลื่อนที่ได้ เพราะแบบจำลองไม่มีกลไกการแลกเปลี่ยนแก๊สจริง

6. กะบังลมกับความดันปอด (หลักการของบอยล์)

หลักการสำคัญที่อธิบายการหายใจคือ กฎของบอยล์ (Boyle's Law): ที่อุณหภูมิคงที่ ความดันของแก๊สจะแปรผกผันกับปริมาตร (เมื่อปริมาตรเพิ่ม ความดันจะลด และในทางกลับกัน)

กะบังลมหดตัว/เคลื่อนต่ำ
→
ปริมาตรช่องอกเพิ่ม
→
ความหนาแน่นอากาศในช่องอกลด
→
ความดันในช่องอกลดลง
(ต่ำกว่าภายนอก)
→
อากาศจากภายนอก
ไหลเข้าสู่ปอด

กฎสำคัญที่ต้องจำ: อากาศเคลื่อนที่จากบริเวณที่มีความดันสูงไปยังบริเวณที่มีความดันต่ำกว่าเสมอ ไม่ใช่ในทิศทางตรงข้าม

⚠️ เข้าใจผิดบ่อยที่สุด อากาศเคลื่อนที่จากความดันต่ำไปความดันสูง
✓ อากาศ (และแก๊สทุกชนิด) เคลื่อนที่จากบริเวณความดัน/ความเข้มข้นสูง ไปยังบริเวณความดัน/ความเข้มข้นต่ำกว่าเสมอ ไม่ว่าจะเป็นการไหลของอากาศเข้าปอด หรือการแพร่ของแก๊สที่ถุงลม

กราฟความดันแก๊สในถุงลม (O₂ vs CO₂)

โจทย์มักให้กราฟความดันย่อยของ O₂ และ CO₂ ในถุงลมที่เปลี่ยนแปลงตามเวลา หลักการอ่านกราฟ:

  • ช่วงที่ความดัน O₂ ในถุงลมลดลง และ CO₂ เพิ่มขึ้น → กำลังเกิดการหายใจออก (กะบังลมยกตัวสูงขึ้น ปริมาตรปอดลดลง)
  • ช่วงที่ความดัน O₂ ในถุงลมเพิ่มขึ้น (จากอากาศใหม่ที่เข้ามา) และ CO₂ ลดลง → กำลังเกิดการหายใจเข้า
  • ความดัน O₂ ในถุงลมจะสูงกว่า ความดัน CO₂ เสมอ เพราะสัดส่วน O₂ ในอากาศ (~21%) สูงกว่า CO₂ (~0.04%) มาก
💡 เทคนิคทำโจทย์กราฟ หากสับสนว่ากราฟเส้นใดคือ O₂ หรือ CO₂ ให้เพ่งดูที่ "เส้นออกซิเจน" เป็นหลัก เพราะทิศทางของออกซิเจนจะสวนทางกับ CO₂ เสมอ และมักตีความง่ายกว่า

7. ศูนย์ควบคุมการหายใจ (เสริมนอกเหนือจากเอกสาร)

เนื้อหานี้ไม่ได้อยู่ในเอกสารต้นฉบับโดยตรง แต่เป็นความรู้ต่อยอดที่ช่วยอธิบายกราฟ "อัตราการหายใจกับความเข้มข้นของแก๊ส" ที่ปรากฏในแบบฝึกหัดได้ลึกซึ้งขึ้น

อัตราการหายใจถูกควบคุมโดย ศูนย์ควบคุมการหายใจ (Respiratory center) ที่ก้านสมองส่วนเมดัลลาออบลองกาตา (Medulla oblongata) ซึ่งตรวจจับการเปลี่ยนแปลงหลักผ่านตัวรับสารเคมี (Chemoreceptors):

  • ปัจจัยหลักที่กระตุ้นการหายใจ: ระดับ CO₂ ในเลือดที่เพิ่มขึ้น (ซึ่งทำให้เลือดมีสภาพเป็นกรดมากขึ้นจากการเกิดกรดคาร์บอนิก H₂CO₃) มีผลกระตุ้นศูนย์ควบคุมการหายใจให้เพิ่มอัตราการหายใจได้ไวและมากกว่าการเปลี่ยนแปลงของระดับ O₂
  • ปัจจัยรอง: ระดับ O₂ ในเลือดที่ลดลงอย่างมาก จะกระตุ้นตัวรับที่หลอดเลือดแดง (Carotid & aortic bodies) แต่มีผลน้อยกว่า CO₂ ในสภาวะปกติ
🔑 เชื่อมโยงกับกราฟในแบบฝึกหัด นี่คือเหตุผลที่กราฟ "อัตราเร็วการหายใจ" จะไวต่อการเปลี่ยนแปลงความเข้มข้นของ CO₂ มากกว่า O₂ เสมอ — สอดคล้องกับข้อสรุปในแบบฝึกหัดที่ระบุว่า "อัตราเร็วในการหายใจได้รับผลกระทบจากการเปลี่ยนแปลงความเข้มข้นของ CO₂ มากกว่า O₂"

ปัจจัยอื่นที่ส่งผลต่อการหายใจ

การรับประทานอาหารมากเกินไปทำให้กระเพาะอาหารขยายตัวไปเบียดกะบังลม ทำให้กะบังลมหดตัว/เคลื่อนต่ำได้ยากขึ้น และปริมาตรช่องอกเพิ่มได้น้อยลง จึงทำให้ ความแตกต่างระหว่างความดันในช่องอกกับความดันภายนอกลดลง ส่งผลให้อากาศเข้าสู่ปอดได้ยากขึ้น (หายใจลำบาก)

8. รวมประเด็นที่เข้าใจผิดบ่อย (Misconceptions)

1) ทิศทางการไหลของอากาศ/แก๊ส คิดว่าแก๊สไหลจากความเข้มข้นต่ำไปสูง
✓ แก๊สและอากาศเคลื่อนที่จาก "มาก/สูง" ไป "น้อย/ต่ำ" เสมอ ทั้งการไหลของอากาศเข้า-ออกปอด และการแพร่ของ O₂/CO₂ ที่ถุงลม
2) กะบังลมกับกระดูกซี่โครง คิดว่ากะบังลมกับกระดูกซี่โครงเคลื่อนที่ไปทิศทางเดียวกัน
✓ ทั้งสองเคลื่อนที่ "สวนทางกัน" เสมอ แต่ทำงานร่วมกันให้ปริมาตรช่องอกเปลี่ยนไปในทิศทางเดียวกัน (เพิ่มพร้อมกันตอนหายใจเข้า)
3) การหายใจระดับเซลล์ vs การแลกเปลี่ยนแก๊ส คิดว่าการแลกเปลี่ยนแก๊สที่ถุงลมคือการหายใจระดับเซลล์
✓ การแลกเปลี่ยนแก๊สเป็นการแพร่ทางกายภาพระหว่างถุงลม/เซลล์กับเลือด ส่วนการหายใจระดับเซลล์คือปฏิกิริยาเคมีในไมโทคอนเดรียที่สลายสารอาหารเป็นพลังงาน
4) หลอดเลือดแดง-ดำ กับปริมาณแก๊ส คิดว่าหลอดเลือดแดงมี O₂ สูงและหลอดเลือดดำมี CO₂ สูงเสมอ
✓ กฎนี้ใช้ไม่ได้กับวงจรปอด — หลอดเลือดแดงปอด (Pulmonary artery) นำเลือดที่มี CO₂ สูงออกจากหัวใจไปยังปอด ส่วนหลอดเลือดดำปอด (Pulmonary vein) นำเลือดที่มี O₂ สูงกลับเข้าสู่หัวใจ (ชื่อ "แดง-ดำ" อ้างอิงทิศทางที่ไหลออก/เข้าหัวใจ ไม่ได้อ้างอิงปริมาณแก๊ส)
5) แบบจำลองการหายใจ คิดว่าแบบจำลอง (ขวดโหล-ลูกโป่ง) บอกชนิดของแก๊สที่เคลื่อนที่ได้
✓ แบบจำลองบอกได้เพียงทิศทางการไหลของ "อากาศ" เท่านั้น ไม่สามารถระบุว่าเป็น O₂ หรือ CO₂ เพราะไม่มีกลไกแลกเปลี่ยนแก๊สจริงอยู่ในแบบจำลอง
6) ปัจจัยกระตุ้นการหายใจ คิดว่า O₂ ต่ำเป็นตัวกระตุ้นหลักให้หายใจเร็วขึ้น
✓ ตัวกระตุ้นหลักคือระดับ CO₂ ในเลือดที่สูงขึ้น (ทำให้เลือดเป็นกรดมากขึ้น) ซึ่งมีผลต่ออัตราการหายใจมากกว่าการเปลี่ยนแปลงของ O₂
7) โครงสร้างแลกเปลี่ยนแก๊สของสิ่งมีชีวิตต่างๆ คิดว่า "มีเส้นเลือดฝอยมาเลี้ยง" เป็นคุณสมบัติพื้นฐานร่วมของทุกโครงสร้างแลกเปลี่ยนแก๊ส
✓ ไม่ใช่ทุกกรณี เช่น ระบบท่อลม (Tracheal system) ของแมลงนำแก๊สเข้าสู่เซลล์โดยตรงโดยไม่ผ่านระบบเลือด คุณสมบัติร่วมที่แท้จริงคือ "ผนังบางชุ่มชื้น" และ "มีพื้นที่ผิวมากเทียบกับปริมาตร"
