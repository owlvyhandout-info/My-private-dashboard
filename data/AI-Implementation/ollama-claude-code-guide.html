04

ดาวน์โหลด • ตรวจสอบ • ลบโมเดล

เลือกชื่อโมเดลและแท็กให้ครบ เช่น :2b การใช้ :latest ไม่ได้แปลว่าเป็นรุ่นเล็กที่สุด และไม่ได้บอกจำนวนพารามิเตอร์

ดาวน์โหลดโมเดลโดยยังไม่เปิดแชทCMD
ollama pull qwen3.5:2b
รายการโมเดลและพื้นที่บนดิสก์CMD
ollama list
ดูรายละเอียดตัวปัจจุบันCMD
ollama show qwen3.5:2b
ดูรายละเอียดตัวเก่าCMD
ollama show qwen2.5:latest
ค่าในผลลัพธ์อ่านอย่างไร
parametersจำนวนพารามิเตอร์ เช่น 7.6B คือประมาณ 7.6 พันล้าน
quantizationรูปแบบลดความละเอียดน้ำหนัก เช่น Q4_K_M มีผลต่อขนาดและคุณภาพ
context lengthขนาดบริบทที่รองรับ ไม่ยืนยันว่าขณะรันจัดสรรครบเท่านี้
SIZE ใน ollama listขนาดข้อมูลโมเดล ไม่ใช่หน่วยความจำทั้งหมดขณะรัน
เอาโมเดลเก่าออกจากหน่วยความจำCMD
ollama stop qwen2.5:latest
ลบตัวเก่า — ใช้เมื่อแน่ใจว่าไม่ต้องการCMD
ollama rm qwen2.5:latest

คำสั่งลบจริง: ตรวจชื่อด้วย ollama list ก่อน ไม่ลบไฟล์งานโปรเจกต์ ดาวน์โหลดกลับได้ภายหลัง

ตรวจรายการหลังลบCMD
ollama list
stop กับ rm ต่างกัน: stop ปลดโมเดลจากหน่วยความจำ แต่ไฟล์ยังอยู่ • rm ลบโมเดลจากดิสก์ • ถ้าโมเดลอื่นใช้ข้อมูลร่วมกัน พื้นที่คืนอาจน้อยกว่าขนาดที่แสดง

ตำแหน่งโมเดล • ไฟล์งาน • Cloud

ต้องการย้ายที่เก็บโมเดลไปไดรฟ์ E
  1. Quit Ollama จาก System tray
  2. เปิด “Edit environment variables for your account” ใน Windows
  3. สร้างตัวแปรผู้ใช้ชื่อ OLLAMA_MODELS เช่นค่า E:\OllamaModels

การตั้งตัวแปรไม่ย้ายไฟล์เดิมให้อัตโนมัติ หากไม่ได้ย้ายข้อมูล จะต้องดาวน์โหลดใหม่
