Google Analytics 4 (GA4) + Firebase Hosting

คู่มือสรุปขั้นตอนการติดตั้ง ประเด็นข้อสงสัย และการดูรายงานผลสำหรับโปรเจกต์ Owlvy SimLab

📌 1. ขั้นตอนการติดตั้งตั้งแต่เริ่มต้น

  • 1
    สร้าง Property บน Google Analytics
    เข้าไปที่ analytics.google.com 🔗 กดไอคอนฟันเฟือง ⚙️ (ผู้ดูแลระบบ) ➔ เลือก + สร้าง Property ➔ ตั้งชื่อ Property (เช่น Prop_SimLabWeb)
  • 2
    ตั้งค่า Data Stream (สตรีมข้อมูล)
    เลือกแพลตฟอร์มเป็น "เว็บ" (Web) ➔ กรอก URL เว็บไซต์ เช่น owlvy-simlab-physics.web.app ➔ ตั้งชื่อสตรีม ➔ ระบบจะสร้างรหัส Measurement ID (เช่น G-0J7ER1GJB...) มาให้
  • 3
    นำโค้ดแท็ก Google ไปติดในไฟล์ HTML
    คัดลอกชุดสคริปต์ gtag.js นำไปวางต่อจากแท็ก <head> ในไฟล์ HTML ที่ต้องการวัดผล (เช่น buoyancy-force-full.html หรือ buoyancy-force-lite.html) 
    <!-- Google tag (gtag.js) -->
<script async src="https://www.googletagmanager.com/gtag/js?id=G-XXXXXXXXXX"></script>
<script>
  window.dataLayer = window.dataLayer || [];
  function gtag(){dataLayer.push(arguments);}
  gtag('js', new Date());

  gtag('config', 'G-XXXXXXXXXX');
</script>
  • 4
    Deploy ขึ้น Firebase Hosting
    เปิด Terminal/Command Prompt ในโฟลเดอร์โปรเจกต์ แล้วสั่ง Deploy ไฟล์ที่อัปเดตแล้วขึ้น Server: 
    firebase deploy --only hosting

❓ 2. ประเด็นและข้อสงสัยสำคัญที่ได้เคลียร์แล้ว

Q: ไม่มีไฟล์ index.html ติดตั้ง GA4 ได้ไหม?
ทำได้แน่นอน: GA4 ทำงานผ่านสคริปต์ JavaScript เบราว์เซอร์ ไม่จำเป็นต้องมี index.html ตราบใดที่ไฟล์ HTML นั้นๆ มีสคริปต์ GA4 ติดอยู่ ระบบจะบันทึก URL นั้นให้อัตโนมัติ
Q: ในระบบขึ้นคำว่า "รายละเอียดโรงแรม" เกิดจากอะไร?
การแปลภาษาคลาดเคลื่อน: คำว่า Property Details โดนแปลเป็นภาษาไทยว่า "รายละเอียดโรงแรม" ในบริบทของ GA4 คำว่า Property หมายถึง "สินทรัพย์ดิจิทัล/เว็บไซต์" สามารถตั้งชื่อและดำเนินการต่อได้ปกติ
Q: ติดสคริปต์ซ้ำกับ <script> เดิมใน HTML จะกระเทือนโค้ดเดิมไหม?
ปลอดภัย 100%: โค้ด GA4 ทำงานแบบ Asynchronous (async) และใช้ตัวแปรเฉพาะขอบเขต (dataLayer, gtag) ไม่ขัดจังหวะการทำงานของสคริปต์เดิมใน SimLab แน่นอน
Q: ถ้าติดแท็กเฉพาะบางไฟล์ เช่น buoyancy-force-full จะเกิดอะไรขึ้น?
นับเฉพาะหน้าที่ติดแท็ก: GA4 ทำงานแบบหน้าต่อหน้า (Page-by-Page) หากผู้ใช้เข้าหน้าอื่นที่ไม่ได้ติดแท็ก ระบบจะไม่เก็บข้อมูลการเข้าชมหน้านั้นๆ
Q: ปุ่มกดทดสอบใน Firebase/Analytics แจ้งว่า "ตรวจไม่พบแท็ก"?
เพราะระบบวิ่งไปเช็กที่ Root URL (/): เว็บไม่มี index.html ทำให้ปุ่มทดสอบวิ่งไปเจอหน้าว่าง/Error 404 ให้มองข้ามปุ่มทดสอบ แล้วเช็กผ่านแท็บ Network (ค้นหา collect สถานะ 204) ใน DevTools แทน ซึ่งยืนยันว่าโค้ดส่งข้อมูลสำเร็จแล้ว

⏳ 3. เงื่อนไขในการแสดงผลข้อมูล

ประเภทรายงาน ระยะเวลาแสดงผล เงื่อนไขและสิ่งที่ต้องระวัง
หน้าเว็บแบบเรียลไทม์ (Realtime) แสดงผลทันที แสดงข้อมูลผู้ใช้เฉพาะคนที่อยู่ในเว็บย้อนหลัง ไม่เกิน 30 นาที หากเปิดทิ้งไว้นานกว่านั้น ตัวเลขจะลดลงเป็น 0
รายงานสรุปภาพรวม (Standard Reports) รอ 24 - 48 ชั่วโมง รายงานเชิงลึก เช่น กราฟประจำวัน, ประเทศ, เบราว์เซอร์, เวลาใช้งานเฉลี่ย ต้องใช้เวลาประมวลผลย้อนหลัง ไม่ขึ้นทันที
การเลือก Property สำคัญมาก ต้องสลับชื่อ Property มุมซ้ายบนให้ตรงกับ Measurement ID (G-XXXXXXXXXX) ที่นำไปติดในไฟล์ HTML ไม่เช่นนั้นจะเห็นข้อมูลเป็น 0 (ดูผิดห้อง)

📊 4. หน้าจอที่ใช้เรียกดูข้อมูล และลิงก์เข้าใช้งาน

สามารถเข้าใช้งาน Google Analytics ได้ผ่านลิงก์: analytics.google.com 🔗 โดยมีเมนูหลักที่ต้องใช้งานดังนี้:

  • หน้าเว็บแบบเรียลไทม์ (Realtime Report):
    📍 แถบเมนูซ้ายมือ ➔ คลิก "หน้าเว็บแบบเรียลไทม์" (ไอคอนแรกสุด)
    ➔ ใช้เช็กว่า ณ ตอนนี้มีคนเปิดเล่น SimLab อยู่กี่คน และเปิดหน้าไหนอยู่
  • รายงานภาพรวม (Reports Overview):
    📍 แถบเมนูซ้ายมือ ➔ คลิก "ภาพรวมรายงาน"
    ➔ สรุปจำนวนผู้ใช้รวม (Users), ผู้ใช้ใหม่ (New Users), และเวลาใช้งานเฉลี่ย (Engagement Time)
  • หน้ายอดนิยม (Pages & Screens):
    📍 ทำความเข้าใจการเข้าชมเว็บ ➔ หน้าเว็บและคลาสหน้าจอ
    ➔ เปรียบเทียบว่าสื่อ SimLab หน้าไหนมีคนเข้าเรียนมากที่สุด (เช่น /buoyancy-force-lite vs /buoyancy-force-full)
  • อุปกรณ์ของผู้ใช้ (Tech Details):
    📍 ผู้ใช้ ➔ เทคโนโลยี ➔ รายละเอียดเทคโนโลยี
    ➔ เช็กว่าผู้เรียนใช้คอมพิวเตอร์ มือถือ หรือแท็บเล็ต ในการใช้งาน SimLab
