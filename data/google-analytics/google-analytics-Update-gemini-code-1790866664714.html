Google Analytics 4 (GA4) + Firebase Hosting

คู่มือสรุปขั้นตอนการติดตั้ง สถาปัตยกรรมโปรเจกต์ เงื่อนไขค่าบริการ และการดูรายงานผล

💡 กฎทองสำหรับโปรเจกต์: 1 Project = 1 Property Name = 1 Tag (Measurement ID)
นำชุดโค้ด Tag เดียวกันนี้ไปวางใส่ทุกไฟล์ HTML (ทั้ง index.html และไฟล์ลูกทุกไฟล์) เพื่อรวมข้อมูลไว้ที่เดียวกัน

📌 1. ขั้นตอนการติดตั้งตั้งแต่เริ่มต้น

  • 1
    สร้างและตั้งชื่อ Property ในระดับ Project Level
    เข้าไปที่ analytics.google.com 🔗 กดไอคอน ⚙️ (ผู้ดูแลระบบ) ➔ เลือก + สร้าง Property ➔ ตั้งชื่อเป็นชื่อโปรเจกต์กลาง (เช่น Physics SimLab) ไม่ตั้งเจาะจงเฉพาะเรื่อง เพื่อให้ครอบคลุมไฟล์ลูกทั้งหมด
  • 2
    ตั้งค่า Data Stream (สตรีมข้อมูล)
    เลือกแพลตฟอร์มเป็น "เว็บ" (Web) ➔ กรอก URL เว็บไซต์หลัก ➔ ตั้งชื่อสตรีม ➔ ระบบจะสร้างรหัส Measurement ID (เช่น G-0J7ER1GJB...)
  • 3
    นำโค้ดแท็กสคริปต์ไปติดในทุกไฟล์ HTML
    คัดลอกสคริปต์ gtag.js นำไปวางในแท็ก <head> ของทุกไฟล์ HTML ในโปรเจกต์ (รวมถึง index.html, buoyancy-force-full.html, buoyancy-force-lite.html, density-lab.html) 
    <!-- Google tag (gtag.js) -->
<script async src="https://www.googletagmanager.com/gtag/js?id=G-0J7ER1GJB..."></script>
<script>
  window.dataLayer = window.dataLayer || [];
  function gtag(){dataLayer.push(arguments);}
  gtag('js', new Date());

  gtag('config', 'G-0J7ER1GJB...');
</script>
    💡 วิธีดึงสคริปต์เดิมกลับมาใช้: ก๊อปปี้จากไฟล์ HTML เดิมที่เคยติดไว้ หรือไปที่ GA4 ➔ Admin ➔ Data Streams ➔ เลือก Stream ➔ View tag instructions ➔ Install manually
  • 4
    Deploy ขึ้น Firebase Hosting
    เปิด Terminal ในโฟลเดอร์โปรเจกต์ แล้วสั่ง Deploy ขึ้น Server: 
    firebase deploy --only hosting

❓ 2. ประเด็นโครงสร้างเว็บและข้อสงสัยสำคัญ

Q: หากมี index.html ที่เป็นหน้ารวม แล้วคลิกไปเรียกไฟล์ลูก ต้องติด Tag อย่างไร?
ติด Tag ตัวเดียวกันในทุกไฟล์: ทั้ง index.html และไฟล์ลูกทุกไฟล์ ต้องใช้ Measurement ID เดียวกัน (เช่น G-0J7ER1GJB...) เพื่อให้ GA4 รวมข้อมูลการเดินทางของผู้เรียน (User Journey) ตั้งแต่หน้ารวมไปจนถึงการเข้าเล่น SimLab หน้าต่างๆ ไว้ในรายงานชุดเดียวกัน
Q: การตั้งชื่อ Property ควรเจาะจงหรือตั้งระดับ Project?
ควรตั้งชื่อระดับ Project: เช่น ตั้งว่า Physics SimLab เพื่อไม่ให้สับสนเวลาเรียกดูรายงานรวมของสื่อหลายๆ เรื่อง (สามารถแก้ไขชื่อได้ที่ Admin ➔ Property Details)
Q: ไม่มีไฟล์ index.html ติดตั้ง GA4 ได้ไหม?
ทำได้ปกติ: GA4 ทำงานแบบหน้าต่อหน้า (Page-by-Page) ตราบใดที่ไฟล์ HTML หน้านั้นๆ มีสคริปต์ GA4 ติดอยู่ ระบบจะบันทึก URL นั้นให้อัตโนมัติ
Q: ปุ่มกดทดสอบใน Analytics แจ้งว่า "ตรวจไม่พบแท็ก"?
เกิดจากระบบวิ่งไปเช็กที่ Root URL (/): ให้มองข้ามปุ่มทดสอบ แล้วเช็กผ่านแท็บ Network (ค้นหา collect สถานะ 204) ใน DevTools แทน ซึ่งยืนยันว่าส่งข้อมูลสำเร็จแล้ว

💰 3. ค่าบริการ เงื่อนไข และโควต้าการใช้งานฟรี

บริการ เงื่อนไขโควต้าฟรี FREE ข้อจำกัดที่ควรรู้
Google Analytics 4 (GA4) • ไม่จำกัดจำนวน Tag / หน้าเว็บ
• ฟรีสูงสุด 10,000,000 Events / เดือน
• สร้างได้สูงสุด 2,000 Properties 		เก็บข้อมูลรายบุคคลย้อนหลังสูงสุด 14 เดือน (ต้องไปปรับตั้งค่าใน Data Retention)
Firebase Hosting (Spark Plan) • ฟรีพื้นที่จัดเก็บข้อมูล 10 GB
• ปริมาณรับส่งข้อมูล (Bandwidth) ฟรี 360 MB/วัน (~10 GB/เดือน) 		เพียงพอสำหรับผู้เข้าชมใช้งาน SimLab หลายพันถึงหมื่นครั้งต่อเดือนโดยไม่มีค่าใช้จ่าย

⏳ 4. เงื่อนไขในการแสดงผลข้อมูล

ประเภทรายงาน ระยะเวลาแสดงผล เงื่อนไขสำคัญ
หน้าเว็บแบบเรียลไทม์ (Realtime) แสดงผลทันที แสดงข้อมูลผู้ใช้เฉพาะคนที่อยู่ในเว็บย้อนหลัง ไม่เกิน 30 นาที
รายงานสรุปภาพรวม (Standard Reports) รอ 24 - 48 ชั่วโมง รายงานเชิงลึก เช่น กราฟประจำวัน, ประเทศ, เบราว์เซอร์, เวลาใช้งานเฉลี่ย ต้องใช้เวลาประมวลผลย้อนหลัง
การเลือก Property สำคัญมาก ต้องสลับเลือก Property มุมซ้ายบนให้ตรงกับ Measurement ID (G-XXXXXXXXXX) ที่นำไปติดในไฟล์ HTML ไม่เช่นนั้นจะเห็นข้อมูลเป็น 0 (ดูผิดห้อง)

📊 5. หน้าจอที่ใช้เรียกดูข้อมูล และลิงก์เข้าใช้งาน

เข้าใช้งาน Google Analytics ได้ที่: analytics.google.com 🔗 โดยมีเมนูหลักดังนี้:

  • หน้าเว็บแบบเรียลไทม์ (Realtime Report):
    📍 แถบเมนูซ้ายมือ ➔ คลิก "หน้าเว็บแบบเรียลไทม์"
    ➔ ใช้เช็กว่า ณ ตอนนี้มีคนเปิดเล่น SimLab อยู่กี่คน และเปิดหน้าไหนอยู่
  • รายงานภาพรวม (Reports Overview):
    📍 แถบเมนูซ้ายมือ ➔ คลิก "ภาพรวมรายงาน"
    ➔ สรุปจำนวนผู้ใช้รวม (Users), ผู้ใช้ใหม่ (New Users), และเวลาใช้งานเฉลี่ย (Engagement Time)
  • หน้ายอดนิยม (Pages & Screens):
    📍 ทำความเข้าใจการเข้าชมเว็บ ➔ หน้าเว็บและคลาสหน้าจอ
    ➔ เปรียบเทียบสถิติการใช้งานแต่ละไฟล์ (เช่น index.html vs /buoyancy-force-lite vs /density-lab)
  • อุปกรณ์ของผู้ใช้ (Tech Details):
    📍 ผู้ใช้ ➔ เทคโนโลยี ➔ รายละเอียดเทคโนโลยี
    ➔ เช็กสัดส่วนผู้ใช้ว่าใช้คอมพิวเตอร์ มือถือ หรือแท็บเล็ต
