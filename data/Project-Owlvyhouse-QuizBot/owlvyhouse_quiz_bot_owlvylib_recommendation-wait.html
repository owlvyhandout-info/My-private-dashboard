🦉 OwlvyLib – OpenRouter Fallback System Guide

1. จุดประสงค์

ระบบนี้ช่วยให้ OwlvyHouse สามารถ:

  • สลับ AI Model อัตโนมัติเมื่อ Model แรกใช้งานไม่ได้
  • Fallback ไปใช้ฟรีเมื่อเครดิตหมด
  • ลดปัญหา Provider ล่ม / Timeout
  • ทำให้ Bot ตอบได้ต่อเนื่อง

2. แก้ไข MODELS

เพิ่ม Free Fallback Model เข้าไปท้ายสุด

const MODELS = [

  // PRIMARY
  "google/gemini-2.5-flash-lite",

  // FALLBACKS
  "deepseek/deepseek-chat",
  "anthropic/claude-3-haiku",
  "meta-llama/llama-3.3-70b-versatile",
  "anthropic/claude-3.5-sonnet",

  // FREE FALLBACK
  "openrouter/free"

];
ถ้า Paid Model ใช้งานไม่ได้ ระบบจะลองใช้ฟรีอัตโนมัติ

3. Function askAI()

Function นี้จะวนลอง Model ทีละตัวจนกว่าจะสำเร็จ

function askAI(userMessage) {

  for (const model of MODELS) {

    try {

      Logger.log("Trying model: " + model);

      const result = callOpenRouter(model, userMessage);

      if (result) {

        Logger.log("SUCCESS: " + model);

        return {
          success: true,
          model: model,
          answer: result
        };

      }

    } catch (err) {

      Logger.log("FAILED: " + model);
      Logger.log(err);

    }

  }

  return {
    success: false,
    answer: "ขออภัย ระบบ AI ไม่พร้อมใช้งานชั่วคราว"
  };

}

4. Function callOpenRouter()

Function นี้เป็นส่วนเรียก OpenRouter API จริง

function callOpenRouter(model, userMessage) {

  const apiKey = PropertiesService
    .getScriptProperties()
    .getProperty("OPENROUTER_API_KEY");

  const url = "https://openrouter.ai/api/v1/chat/completions";

  const payload = {

    model: model,

    messages: [
      {
        role: "user",
        content: userMessage
      }
    ],

    max_tokens: 1000,
    temperature: 0.7

  };

  const options = {

    method: "post",

    contentType: "application/json",

    headers: {
      "Authorization": "Bearer " + apiKey
    },

    payload: JSON.stringify(payload),

    muteHttpExceptions: true

  };

  const response = UrlFetchApp.fetch(url, options);

  const code = response.getResponseCode();

  Logger.log("HTTP CODE: " + code);

  if (code !== 200) {

    throw new Error(
      "API ERROR " + code + " : " + response.getContentText()
    );

  }

  const data = JSON.parse(response.getContentText());

  if (
    !data.choices ||
    !data.choices[0] ||
    !data.choices[0].message
  ) {

    throw new Error("Invalid response");

  }

  return data.choices[0].message.content;

}

7. Development Mode (แนะนำตอนพัฒนา)

ถ้ากำลังทดลองระบบ แนะนำให้เปิด:

Use development mode

ข้อดี:

  • แก้ Library → ใช้ได้ทันที
  • ไม่ต้อง Deploy ทุกครั้ง
  • เหมาะกับการ Debug
Production จริงควรกลับมาใช้ Fixed Version เพื่อความเสถียร
