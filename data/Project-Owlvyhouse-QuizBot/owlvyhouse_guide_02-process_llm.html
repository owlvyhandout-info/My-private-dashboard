อนุญาตสิทธิ์ครบทุก scope ห้ามข้าม
⚠️ Google ขอสิทธิ์ทีละส่วน ไม่พร้อมกัน ถ้าไม่รัน authorizeAll จะเกิด error "You do not have permission" ภายหลัง
เลือกฟังก์ชัน authorizeAll → กดรัน ▶ Run → Review permissions → Allow
✅ ดู log ใน Executions ต้องเห็น: ✅ Authorized ครบทุก scope แล้ว
หลังจากนี้ไม่ต้องรัน authorizeAll อีก และไม่กระทบการทำงานปกติ
เช็คยืนยัน — ⚙️ → Project Settings → OAuth scopes ต้องเห็นครบ 3 บรรทัดนี้
Scope ใช้สำหรับ
https://www.googleapis.com/auth/script.external_request เชื่อมต่ออินเทอร์เน็ต → OpenRouter API
https://www.googleapis.com/auth/spreadsheets อ่าน/เขียน Spreadsheet
https://www.googleapis.com/auth/gmail.send ส่งเมลหานักเรียน
