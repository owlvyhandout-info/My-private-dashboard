หน่วยที่ 2 — สารละลาย
ครอบคลุมมัธยมต้น–ปลาย · เรียงตามลำดับการเรียนรู้
บทที่ 1 องค์ประกอบของสารละลายและปัจจัยที่มีผลต่อสภาพละลายได้ ▼
องค์ประกอบของสารละลาย
ตัวละลาย + ตัวทำละลาย
สารละลาย คือ ของผสมเนื้อเดียวกัน (homogeneous mixture) ที่มีองค์ประกอบ 2 ส่วน
  • ตัวทำละลาย (solvent) — ปริมาณมากกว่า กำหนดสถานะ เช่น น้ำ, แอลกอฮอล์
  • ตัวละลาย (solute) — ปริมาณน้อยกว่า ถูกละลาย เช่น เกลือ, น้ำตาล, ก๊าซ CO₂
น้ำเกลือ น้ำหวาน น้ำโซดา ทองเหลือง
น้ำเป็น "ตัวทำละลายสากล" เพราะโมเลกุลมีขั้วละลายสารขั้วได้ดีที่สุด (like dissolves like)
สารละลายอิ่มตัวและสภาพละลายได้
ประเภทสารละลายตามความเข้มข้น
  • ไม่อิ่มตัว (unsaturated) — ละลายตัวละลายเพิ่มได้อีก
  • อิ่มตัว (saturated) — ละลายได้สูงสุดที่อุณหภูมิหนึ่ง
  • อิ่มตัวยวดยิ่ง (supersaturated) — ละลายเกินจุดอิ่มตัว ไม่เสถียร
สภาพละลายได้ = ปริมาณตัวละลายสูงสุด (g)
ที่ละลายได้ใน ตัวทำละลาย 100 g ณ อุณหภูมิหนึ่ง
ปัจจัยที่มีผลต่อสภาพละลายได้
อุณหภูมิ (Temperature)
ผลของอุณหภูมิขึ้นอยู่กับว่าปฏิกิริยาการละลายเป็นแบบใด
คายความร้อน (Exothermic)
ΔH < 0
ละลายได้ดีกว่าที่ อุณหภูมิต่ำ
อุณหภูมิ↑ → สภาพละลายได้↓
เช่น NaOH, HCl, Ca(OH)₂, ก๊าซในน้ำ
ดูดความร้อน (Endothermic)
ΔH > 0
ละลายได้ดีกว่าที่ อุณหภูมิสูง
อุณหภูมิ↑ → สภาพละลายได้↑
เช่น KNO₃, NH₄NO₃, น้ำตาล
กราฟ solubility curve แสดงความสัมพันธ์ T กับ solubility — ใช้อ่านว่าสารใดอิ่มตัว/ไม่อิ่มตัวที่ T ใด
ความดัน (Pressure)
มีผลเฉพาะ ก๊าซ ที่ละลายในของเหลว
ความดัน↑ → สภาพละลายได้ของก๊าซ↑
กฎของ Henry: S = k·P
S = สภาพละลายได้ก๊าซ, k = ค่าคงที่ Henry, P = ความดันย่อยก๊าซ
ตัวอย่าง: น้ำอัดลมอัดก๊าซ CO₂ ความดันสูง → ซ่า เปิดฝา → ความดันลด → ก๊าซออก
ธรรมชาติของตัวละลาย/ตัวทำละลาย
หลัก "Like dissolves like"
สารขั้ว (polar) ละลายในตัวทำละลายขั้ว
สารไม่มีขั้ว (nonpolar) ละลายในตัวทำละลายไม่มีขั้ว
NaCl + น้ำ ✓ ไขมัน + เฮกเซน ✓ ไขมัน + น้ำ ✗
บทที่ 2 ความเข้มข้นของสารละลาย ▼
ร้อยละโดยมวล (%w/w)
%w/w — มัธยมต้น
%w/w = (มวลตัวละลาย / มวลสารละลาย) × 100
ตัวอย่าง: เกลือ 5 g ในสารละลาย 100 g → 5%w/w
ร้อยละโดยปริมาตร (%v/v)
%v/v — ของเหลวในของเหลว
%v/v = (ปริมาตรตัวละลาย / ปริมาตรสารละลาย) × 100
ตัวอย่าง: แอลกอฮอล์ 70 mL ใน 100 mL → เอทานอล 70%
ร้อยละมวลต่อปริมาตร (%w/v)
%w/v — ห้องปฏิบัติการ
%w/v = (มวลตัวละลาย (g) / ปริมาตรสารละลาย (mL)) × 100
ตัวอย่าง: น้ำเกลือ 0.9%w/v = NaCl 0.9 g ใน 100 mL
หน่วยความเข้มข้นระดับมัธยมปลาย
โมลาริตี (Molarity, M)
mol/L — หน่วยมาตรฐาน
M = จำนวนโมลตัวละลาย (mol) / ปริมาตรสารละลาย (L)
n = m / Mᵣ → หาโมลก่อน แล้วหาร V
เช่น NaOH 40 g ใน 1 L → M = 40/40 = 1 M
โมแลลิตี (Molality, m)
mol/kg — ใช้กับ colligative
m = จำนวนโมลตัวละลาย / มวลตัวทำละลาย (kg)
ไม่เปลี่ยนตามอุณหภูมิ เหมาะสำหรับคำนวณ colligative properties
เศษส่วนโมล (Mole fraction, X)
ไม่มีหน่วย
Xₐ = nₐ / (nₐ + n_B + …)
X_ตัวละลาย + X_ตัวทำละลาย = 1
ใช้ใน Raoult's law คำนวณความดันไอ
บทที่ 3 กระบวนการละลายและพลังงาน ▼
3 ขั้นตอนพลังงานการละลาย
วัฏจักรพลังงาน (ไอออนิก)
  1. แยกพันธะผลึก → พลังงานโครงผลึก (ดูดความร้อน +)
  2. แยกโมเลกุลน้ำ → พลังงานแยกตัวทำละลาย (ดูด +)
  3. ไอออน + น้ำ → พลังงานไฮเดรชัน (คายความร้อน −)
ΔH_soln = ΔH_lattice + ΔH_hydration
ผลลัพธ์พลังงานและอุณหภูมิ
เชื่อมกับสภาพละลายได้
คายความร้อน ΔH < 0
อุณหภูมิ↑ ยับยั้งการละลาย
ละลายดีที่ T ต่ำ
NaOH, H₂SO₄, HCl, Ca(OH)₂
ดูดความร้อน ΔH > 0
อุณหภูมิ↑ ส่งเสริมการละลาย
ละลายดีที่ T สูง
KNO₃, NH₄Cl, น้ำตาล
หลัก Le Chatelier: เพิ่มอุณหภูมิ → ระบบต้านด้วยปฏิกิริยาดูดความร้อน ดังนั้น สารที่ละลายแบบดูดความร้อนจะละลายได้มากขึ้นเมื่ออุณหภูมิสูง และสารที่ละลายแบบคายความร้อนจะละลายได้น้อยลง
เอนโทรปีและทิศทางการละลาย
ΔG = ΔH − TΔS
การละลายเกิดขึ้นเองเมื่อ ΔG < 0
แม้ ΔH > 0 ก็ยังละลายได้ถ้า TΔS มากพอ
ΔS มักเป็นบวกในการละลาย (ความไม่เป็นระเบียบเพิ่ม)
ΔG = ΔH − TΔS < 0 → ละลายเอง
บทที่ 4 คุณสมบัติ Colligative ของสารละลาย ม.ปลาย ▼
คุณสมบัติเหล่านี้ขึ้นกับ จำนวนอนุภาคตัวละลาย ไม่ขึ้นกับชนิดสาร — ใช้โมแลลิตี (m) ในการคำนวณ
1. การลดลงของความดันไอ
Vapor Pressure Lowering
P_soln = X_solvent · P°_solvent
ΔP = X_solute · P°_solvent
ตัวละลายที่ไม่ระเหยลดความดันไอตัวทำละลาย (กฎของ Raoult)
ตัวอย่างในชีวิตประจำวัน
  • 🧂น้ำเกลือหรือน้ำเชื่อมระเหยช้ากว่าน้ำบริสุทธิ์ — ทำให้อาหารหมักดองแห้งช้าและเก็บได้นาน
  • 🌊น้ำทะเลระเหยช้ากว่าน้ำจืด เนื่องจากมีเกลือแร่ละลายอยู่มาก ส่งผลต่อวัฏจักรน้ำ
  • 🔬ในอุตสาหกรรมยา ใช้ตัวทำละลายผสมเพื่อลดความดันไอ ป้องกันการระเหยของส่วนผสมที่ระเหยง่าย
2. การเพิ่มของจุดเดือด
Boiling Point Elevation (ΔT_b)
ΔT_b = K_b · m · i
K_b น้ำ = 0.512 °C·kg/mol | i = van't Hoff factor
NaCl → i=2, น้ำตาล → i=1
ตัวอย่างในชีวิตประจำวัน
  • 🍝ต้มมะกะโรนีในน้ำเดือด — ใส่เกลือในน้ำต้มทำให้น้ำมีจุดเดือดสูงขึ้นเล็กน้อย อาหารสุกเร็วขึ้น
  • 🚗สารหล่อเย็นรถยนต์ (coolant/antifreeze) ผสม ethylene glycol ทำให้น้ำในหม้อน้ำเดือดที่อุณหภูมิสูงขึ้น ป้องกันเครื่องยนต์ร้อนจัด
  • 🍬การทำลูกอม/น้ำเชื่อม — ต้มน้ำตาลเข้มข้นจนอุณหภูมิสูงกว่า 100°C เพื่อให้ได้เนื้อสัมผัสตามต้องการ
3. การลดลงของจุดเยือกแข็ง
Freezing Point Depression (ΔT_f)
ΔT_f = K_f · m · i
K_f น้ำ = 1.86 °C·kg/mol
จุดเยือกแข็งสารละลาย = 0°C − ΔT_f
ตัวอย่างในชีวิตประจำวัน
  • ❄️โรยเกลือบนถนนหิมะ — NaCl ลดจุดเยือกแข็งของน้ำต่ำกว่า 0°C ป้องกันน้ำแข็งก่อตัวบนพื้นผิวถนน
  • 🚘น้ำยา antifreeze ผสม ethylene glycol ป้องกันน้ำในหม้อน้ำไม่ให้แข็งตัวในฤดูหนาวที่อุณหภูมิต่ำกว่า 0°C
  • 🍦ทำไอศกรีมแบบโบราณ — แช่ภาชนะในน้ำแข็งผสมเกลือ ซึ่งเย็นต่ำกว่า 0°C ทำให้ไอศกรีมแข็งตัวได้
  • 🩸เลือดและน้ำเลี้ยงในเซลล์มีจุดเยือกแข็งต่ำกว่า 0°C เพราะมีสารละลายต่าง ๆ ป้องกันเซลล์แข็งตัวในอากาศเย็น
4. ออสโมซิสและความดันออสโมติก
Osmotic Pressure (π)
π = MRT
M = โมลาริตี, R = 0.08206 L·atm/mol·K, T (K)
น้ำซึมผ่านเยื่อกึ่งซึมผ่านได้จากสารละลายเจือ → เข้มข้น
ตัวอย่างในชีวิตประจำวัน
  • 💧เครื่องกรองน้ำ RO (Reverse Osmosis) — อัดความดันสูงกว่าความดันออสโมติกเพื่อดันน้ำบริสุทธิ์ผ่านเมมเบรน กรองเกลือและสิ่งปนเปื้อนออก
  • 🥗ผักเหี่ยวเมื่อโรยเกลือ — เกลือดึงน้ำออกจากเซลล์ผักผ่านออสโมซิส (hypertonic) ทำให้เซลล์เสียน้ำและเหี่ยวลง
  • 🏥น้ำเกลือ 0.9% (normal saline) สำหรับให้สารน้ำทางหลอดเลือด — เป็น isotonic กับเลือด ไม่ทำให้เม็ดเลือดแดงแตกหรือเหี่ยว
  • 🌿รากต้นไม้ดูดน้ำจากดิน — ความเข้มข้นของน้ำเลี้ยงในรากสูงกว่าน้ำในดิน น้ำจึงซึมเข้ารากตามออสโมซิสโดยไม่ต้องใช้พลังงาน
isotonic = ความดันเท่ากัน | hypertonic → เซลล์เหี่ยว (plasmolysis) | hypotonic → เซลล์บวม/แตก (lysis)
ตัวประกอบ van't Hoff (i)
ไม่แตกตัว (น้ำตาล, กลูโคส): i = 1  |  NaCl → Na⁺ + Cl⁻: i = 2  |  CaCl₂ → Ca²⁺ + 2Cl⁻: i = 3  |  Fe(NO₃)₃: i = 4
