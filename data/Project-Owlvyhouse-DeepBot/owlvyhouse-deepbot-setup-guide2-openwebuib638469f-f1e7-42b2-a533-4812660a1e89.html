ตั้งค่า Firestore Database
สร้างฐานข้อมูลและเก็บ API Key + ข้อมูล Admin
⏱ 5 นาที
  • 1
    Firebase Console → Firestore Database → Create Database
  • 2
    เลือก Start in Production Mode → Next
  • 3
    เลือก Region: asia-southeast1 (Singapore) → Done
  • 4
    สร้าง Collection config → Document openrouter
  • 5
    สร้าง Collection users → Document [Admin Email]
Collection: config / Document: openrouter
Field : apiKey Type : string Value : sk-or-v1-xxxxxxxxxxxxxxxxxxxx (Key จากขั้นตอนที่ 1)
Collection: users / Document: [your-email@gmail.com]
Field : role Type : string Value : admin
ℹ️
Document ID ของ users ต้องเป็น Email จริงของ Admin เช่น example@gmail.com ตรงตัวพิมพ์เล็กพิมพ์ใหญ่

Firestore Security Rules
rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { // OpenRouter API Key // อ่านได้เฉพาะ Login แล้ว / ห้าม Write match /config/{doc} { allow read: if request.auth != null; allow write: if false; } // Users และ Role Admin // อ่านได้เฉพาะเจ้าของ Email / ห้าม Write match /users/{email} { allow read: if request.auth != null && request.auth.token.email == email; allow write: if false; } // Questions (สำหรับอนาคต) match /questions/{docId} { allow read, write: if request.auth != null; } // ปิดกั้นทุกอย่างที่เหลือ match /{document=**} { allow read, write: if false; } } }
✅
ทดสอบ Rules ด้วย Playground: ไม่ Login → อ่าน config → ต้องได้ ❌ DENIED เสมอ
