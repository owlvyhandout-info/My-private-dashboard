🦉 คู่มือ Firebase + GitHub Pages Setup
ทำซ้ำได้ทุกครั้ง | อ่านแล้วปฏิบัติได้เลย

📋 ภาพรวมทั้งหมด

ลำดับ งาน ทำที่ไหน ระดับความสำคัญ
1 ใส่ Firebase Config จริงใน index.html GitHub สำคัญมาก
2 ตั้งค่า Firestore Rules Firebase Console สำคัญมาก
3 สร้าง Document เก็บ API Key Firebase Console สำคัญมาก
4 เปิด Google Authentication Firebase Console สำคัญ
5 เพิ่ม Authorized Domain Firebase Console สำคัญ
6 Hard Refresh ทดสอบ Browser ทดสอบ

🔧 ขั้นตอนที่ 1: ใส่ Firebase Config

1เปิด Firebase Console
https://console.firebase.google.com
→ เลือก Project ของคุณ
→ ⚙️ Project Settings
→ เลื่อนลงหา "Your apps"
→ เลือก Tab "Config"
2Copy firebaseConfig
const firebaseConfig = {
  apiKey: "AIzaSy...",
  authDomain: "your-app.firebaseapp.com",
  projectId: "your-app",
  storageBucket: "your-app.firebasestorage.app",
  messagingSenderId: "123456789",
  appId: "1:123456789:web:abc..."
};
3แก้ใน GitHub → index.html
กด Ctrl+F พิมพ์: YOUR_API_KEY
แทนที่ทุกค่าด้วยค่าจริงจาก Firebase Console
Commit changes
ค่าทุกตัวต้องตรงกับใน Firebase Console เป๊ะ ห้ามเว้นวรรคหรือตัดออก
ตัวเล็กตัวใหญ่ต้องเหมือนกันทุกตัวอักษร
เช็คได้ที่ projectId ต้องตรงกับชื่อ Project ใน Firebase

🔒 ขั้นตอนที่ 2: ตั้งค่า Firestore Rules

1เปิด Firestore Rules
Firebase Console
→ Firestore Database
→ Tab "Rules"
2วางโค้ดนี้แทนที่ของเดิม
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /config/{doc} {
      allow read: if request.auth != null;
      allow write: if false;
    }
  }
}
3กด Publish
ถ้า Rules เป็น allow read, write: if false → เว็บอ่านข้อมูลไม่ได้เลย
ถ้า Rules เป็น allow read, write: if true → ทุกคนอ่านเขียนได้ ไม่ปลอดภัย
Rules ที่ใช้จะให้อ่านได้เฉพาะคนที่ Login แล้วเท่านั้น

🔑 ขั้นตอนที่ 3: สร้าง Document เก็บ API Key

1เปิด Firestore Data
Firebase Console
→ Firestore Database
→ Tab "Data"
→ กด "+ Start collection"
2สร้าง Collection และ Document
ช่อง ค่าที่ใส่ หมายเหตุ
Collection ID config ต้องตรงกับในโค้ด
Document ID openrouter ต้องตรงกับในโค้ด
Field apiKey ต้องตรงกับในโค้ด
Type string เลือก string เสมอ
Value sk-or-xxxxxxxxx API Key จริงจาก OpenRouter
3กด Save
ชื่อ Collection, Document, Field ต้องตรงกับในโค้ด index.html เป๊ะ!
ตัวเล็กตัวใหญ่ต้องเหมือนกัน: apiKey ≠ ApiKey ≠ APIKEY
เช็คในโค้ดด้วย Ctrl+F พิมพ์: doc(db, แล้วดูชื่อ Collection และ Document
เช็คในโค้ดด้วย Ctrl+F พิมพ์: snap.data(). แล้วดูชื่อ Field

🔐 ขั้นตอนที่ 4: เปิด Google Authentication

1เปิด Authentication
Firebase Console
→ Authentication
→ Tab "Sign-in method"
→ คลิก "Google"
→ Toggle เปิด Enable
→ ใส่ Support Email
→ กด Save
ถ้าไม่เปิด Google → ปุ่ม Login ด้วย Google จะใช้งานไม่ได้
เช็คว่า Status เป็น "Enabled" สีเขียว

🌐 ขั้นตอนที่ 5: เพิ่ม Authorized Domain

1เพิ่ม Domain
Firebase Console
→ Authentication
→ Tab "Settings"
→ "Authorized domains"
→ กด "Add domain"
→ ใส่: your-username.github.io
→ กด Add
ถ้าไม่เพิ่ม Domain → Login จะ Error "unauthorized domain"
Domain ที่ต้องมี: localhost และ your-username.github.io

⚙️ ตัวแปรสำคัญที่ต้องระวัง

ตัวแปร/ค่า ถ้าผิด เช็คที่ไหน
apiKey ใน firebaseConfig Firebase ไม่ทำงานเลย Firebase Console → Project Settings
projectId ใน firebaseConfig เชื่อมต่อ Project ผิด ต้องตรงกับชื่อ Project
Collection ID ใน Firestore หาข้อมูลไม่เจอ โค้ด: doc(db, 'config', ...)
Document ID ใน Firestore หาข้อมูลไม่เจอ โค้ด: doc(db, ..., 'openrouter')
Field Name ใน Firestore ได้ค่า undefined โค้ด: snap.data().apiKey
OpenRouter API Key เรียก AI ไม่ได้ openrouter.ai → Keys

🚨 Error ที่พบบ่อย และวิธีแก้

Error สาเหตุ วิธีแก้
Missing or insufficient permissions Firestore Rules ปิดอยู่ แก้ Rules → Publish
ไม่พบ API Key ใน Firestore ชื่อ Collection/Document/Field ไม่ตรง เช็คชื่อให้ตรงกับในโค้ด
unauthorized domain ยังไม่เพิ่ม Domain Authentication → Settings → Add domain
Firebase: No Firebase App Config ผิดหรือยังเป็น Placeholder ใส่ค่าจริงจาก Firebase Console
favicon.ico 404 ไม่มีไอคอนเว็บ ไม่ต้องสนใจ ไม่กระทบการทำงาน
SyntaxError โค้ดผิด syntax เช็ค parentheses () ให้ครบ

✅ Checklist ก่อนทดสอบ

  • Firebase Config ใส่ค่าจริงทุกตัว ไม่มี YOUR_API_KEY เหลืออยู่
  • Firestore Rules Publish แล้ว
  • Firestore มี Collection: config
  • Firestore มี Document ชื่อตรงกับในโค้ด
  • Firestore Field ชื่อตรงกับในโค้ด (ตัวเล็กใหญ่ถูกต้อง)
  • OpenRouter API Key ใส่ครบถ้วน
  • Google Authentication เปิดแล้ว
  • Authorized Domain เพิ่มแล้ว
  • Commit & Push ขึ้น GitHub แล้ว
  • Hard Refresh ด้วย Ctrl+Shift+R

2เช็คชื่อตัวแปรในโค้ด
เปิด index.html
Ctrl+F พิมพ์: doc(db,
→ ดูชื่อ Collection และ Document

Ctrl+F พิมพ์: snap.data()
→ ดูชื่อ Field

นำไปเทียบกับใน Firestore ให้ตรงกัน
