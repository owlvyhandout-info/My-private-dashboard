🦉 สรุปขั้นตอนตั้งค่า Firebase

คู่มือเตรียมระบบหลังบ้านและการเชื่อมต่อสำหรับ Owlvy Academy

1️⃣ การสร้าง Firebase Project (โปรเจกต์ใหม่)

ไปที่ Firebase Console กด "Add Project" ตั้งชื่อโปรเจกต์ (เช่น Owlvy-Gate) และเลือกเปิด/ปิด Google Analytics ตามต้องการ

⚠️ ข้อควรระวัง

  • Project ID จะถูกสร้างขึ้นอัตโนมัติและไม่สามารถเปลี่ยนชื่อได้ในภายหลัง ควรตรวจดูให้แน่ใจว่าชื่ออ่านง่าย
  • หากเปิด Google Analytics ไว้ ระบบจะบังคับให้เลือก Account ของ Analytics ในขั้นตอนถัดไป (ถ้าโปรเจกต์เล็ก แนะนำให้ปิดไปก่อนเพื่อความรวดเร็ว)
2️⃣ การสร้าง App (ลงทะเบียนเว็บ)

ที่หน้าหลักของโปรเจกต์ ให้คลิกไอคอนรูป </> (Web) เพื่อลงทะเบียนหน้าเว็บของเราเข้ากับ Firebase

⚠️ ข้อควรระวัง

  • ไม่ต้องติ๊กเลือก "Also set up Firebase Hosting" หากคุณครูใช้งานผ่าน GitHub Pages อยู่แล้ว

💾 ค่าที่ต้องนำไปใช้ต่อ (สำคัญมาก)

ระบบจะแสดงโค้ด firebaseConfig ให้คุณครู คัดลอก (Copy) ข้อมูลในปีกกานี้เก็บไว้ทั้งหมด (ประกอบด้วย apiKey, authDomain, projectId ฯลฯ)

3️⃣ การเปิดระบบยืนยันตัวตน (Authentication)

ไปที่เมนู Build > Authentication กด Get Started แล้วเลือก Google เป็น Sign-in method

⚠️ ข้อควรระวัง

  • อย่าลืม "เปิดสวิตช์ (Enable)" ที่มุมขวาบน
  • ต้องเลือก Support email (อีเมลของคุณครู) ในช่อง Dropdown ให้เรียบร้อย ไม่เช่นนั้นระบบจะกดเซฟไม่ได้และล็อกอินจะพัง
4️⃣ การสร้าง Database (Firestore)

ไปที่เมนู Build > Firestore Database กด Create Database เลือก Location เป็น Singapore (asia-southeast1) หรือใกล้เคียง

⚠️ ข้อควรระวัง

  • หากเลือก "Start in Test Mode" ระบบจะอนุญาตให้อ่าน/เขียนข้อมูลได้อิสระ แต่มีอายุจำกัดแค่ 30 วัน! เมื่อระบบเปิดใช้งานจริง ควรไปที่แท็บ Rules เพื่อปรับกฎความปลอดภัย (Security Rules) ถาวร

💾 ค่าที่ต้องนำไปใช้ต่อ

ชื่อ Collection (กล่องเก็บข้อมูล) ที่คุณครูคิดไว้ เช่น "registered_students" จะต้องนำไปเขียนในโค้ด app.js ให้ตรงกันเป๊ะๆ (ตัวพิมพ์เล็ก-ใหญ่มีผล)

5️⃣ กำหนด Domain (แก้ปัญหาล็อกอินวนลูป)

ไปที่ Authentication > Settings > Authorized domains แล้วกดปุ่ม Add domain

⚠️ ข้อควรระวัง (จุดตายของมือถือ)

  • หากไม่เพิ่มโดเมนหน้าเว็บของคุณครูลงในนี้ ระบบ Google Login บนมือถือจะบล็อกการเข้าถึงและดีดกลับทันที

💾 ค่าที่ต้องนำไปใช้ต่อ

ต้องพิมพ์ชื่อ Domain โดยไม่ต้องมี https:// หรือ / ต่อท้าย เช่น พิมพ์แค่ owlvyhouse.github.io

💻 การนำค่าไปใส่ใน Code (index.html & app.js)

เมื่อได้ค่า firebaseConfig จากขั้นตอนที่ 2 มาแล้ว ให้นำมาประกอบร่างดังนี้ครับ:

1. ไฟล์ index.html

ในหน้า HTML ไม่ต้องใส่ค่า Config เพียงแค่เรียกใช้ app.js แบบ Module และเตรียมปุ่มไว้ให้พร้อม

<body> <!-- ปุ่มเข้าสู่ระบบ --> <button id="btn-login">เข้าสู่ระบบด้วย Google</button> <!-- จุดสำคัญ: ต้องใส่ type="module" เสมอเพื่อให้ Import Firebase ทำงานได้ --> <script type="module" src="app.js"></script> </body>

2. ไฟล์ app.js

นำก้อน firebaseConfig มาวาง และเชื่อมต่อระบบ Login + Database

import { initializeApp } from "https://www.gstatic.com/firebasejs/10.8.0/firebase-app.js"; import { getAuth, signInWithPopup, GoogleAuthProvider } from "https://www.gstatic.com/firebasejs/10.8.0/firebase-auth.js"; import { getFirestore } from "https://www.gstatic.com/firebasejs/10.8.0/firebase-firestore.js"; // 🚨 นำค่าจาก ข้อ 2 (การสร้าง App) มาวางทับตรงนี้ 🚨 const firebaseConfig = { apiKey: "AIzaSy... ของครู", authDomain: "owlvy-gate.firebaseapp.com", projectId: "owlvy-gate", storageBucket: "owlvy-gate.firebasestorage.app", messagingSenderId: "123456789", appId: "1:123456789:web:abcdef" }; // เริ่มต้นระบบ const app = initializeApp(firebaseConfig); const auth = getAuth(app); const db = getFirestore(app); // เตรียมพร้อมใช้ Database (ข้อ 4) const provider = new GoogleAuthProvider(); // ผูกคำสั่งกับปุ่มใน index.html document.getElementById('btn-login').addEventListener('click', () => { signInWithPopup(auth, provider) .then((result) => { console.log("ล็อกอินสำเร็จ!", result.user.displayName); // เขียนโค้ดส่งไปหน้า Gem หรือบันทึกชื่อลง Firestore ตรงนี้ }) .catch((error) => { console.error("เกิดข้อผิดพลาด:", error); }); });
