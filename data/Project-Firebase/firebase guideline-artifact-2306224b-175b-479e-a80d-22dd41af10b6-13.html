🤖 ใช้กับ Automation ได้อย่างไร

Firebase เป็น Database กลางที่ทุก Automation เข้าถึงได้ ไม่ว่าจะเป็น n8n, Python Script, Bot Line หรือเว็บ Dashboard
📥 เก็บข้อมูลจาก Automation
n8n / Bot รันแล้วบันทึก Log, ผลลัพธ์, Error ลง Firestore อ่านได้จาก Dashboard ทันที
⚙️ เก็บ Config กลาง
เก็บ API Key, Prompt, Setting ใน Firestore แก้ครั้งเดียว ทุก Bot ได้ค่าใหม่ทันที ไม่ต้องแก้โค้ด
💬 เก็บประวัติ Chat
ทุกข้อความที่ User คุยกับ Bot บันทึกลง Firestore วิเคราะห์ได้ว่าถามอะไรบ้าง
🔄 แชร์ข้อมูลระหว่าง Workflow
n8n Workflow A เขียนข้อมูล → Workflow B อ่านต่อ โดยใช้ Firestore เป็นตัวกลาง
⏱️ Queue งาน
เพิ่มงานเข้า Firestore → n8n Poll มาทำ → อัปเดตสถานะกลับ จัดคิวงานได้โดยไม่ต้องมี Queue Server
📡 Webhook ผ่าน Functions
Cloud Functions รับ Webhook จากภายนอก แล้วเขียนลง Firestore ให้ n8n ไปดึงต่อ

│   └── {log_id}/
│       ├── workflow_name
│       ├── status
│       ├── error_message
│       └── timestamp
│

        ├── display_name

        └── last_login
