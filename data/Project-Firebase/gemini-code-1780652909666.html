1. สรุปขั้นตอนการติดตั้งระบบ (เวอร์ชันล่าสุดแบบ Multi-site)

เป้าหมายของโครงสร้างนี้: เราต้องการใช้โปรเจกต์ owlvyhouseacademy-gate เพียงโปรเจกต์เดียว แต่สามารถแบ่ง URL ออกเป็น 2 เว็บไซต์ คือ (1) หน้ารวม Portal และ (2) แอป Gemini Gem โดยทั้งสองแอปใช้ฐานข้อมูลร่วมกัน

ขั้นตอนที่ 1: ตั้งค่าบน Firebase Console (Web)

  • ไปที่ Firebase Console เข้าโปรเจกต์ owlvyhouseacademy-gate
  • ไปที่เมนู Hosting เลื่อนลงล่างสุด คลิกปุ่ม "Add another site"
  • ตั้งชื่อไซต์ใหม่สำหรับหน้ารวม เช่น owlvyhouse-portal (จะได้โดเมน owlvyhouse-portal.web.app)

ขั้นตอนที่ 2: จัดเตรียม Folder ในคอมพิวเตอร์

สร้างโฟลเดอร์หลักขึ้นมา 1 โฟลเดอร์ (เช่น owlvy-project) และสร้างโฟลเดอร์ย่อยด้านในแยกตามแอป:

📁 owlvy-project (โฟลเดอร์หลัก)
  ├── 📁 portal-app      (ใส่ไฟล์ index.html ของหน้ารวม)
  ├── 📁 public          (ใส่ไฟล์ของแอป Gemini Gem ตัวเดิม)
  └── 📄 firebase.json   (ไฟล์ควบคุมเส้นทาง)

ขั้นตอนที่ 3: ตั้งค่าไฟล์ firebase.json (สำคัญที่สุด)

สร้างหรือแก้ไขไฟล์ firebase.json ให้อยู่นอกสุด เพื่อระบุว่าโฟลเดอร์ไหน วิ่งไปที่ไซต์ไหน:

{
  "hosting": [
    {
      "target": "portal-site",
      "public": "portal-app",
      "ignore": ["firebase.json", "**/.*", "**/node_modules/**"]
    },
    {
      "target": "gemini-site",
      "public": "public",
      "ignore": ["firebase.json", "**/.*", "**/node_modules/**"]
    }
  ]
}

ขั้นตอนที่ 4: ผูก Target และอัปโหลด (ผ่าน Command Line)

เปิด Terminal ที่โฟลเดอร์หลัก แล้วพิมพ์คำสั่งผูกชื่อ Target เข้ากับชื่อ Site จริงที่อยู่บนเว็บ:

// ผูกชื่อไซต์ของหน้ารวม
firebase target:apply hosting portal-site owlvyhouse-portal

// ผูกชื่อไซต์ของแอป Gemini
firebase target:apply hosting gemini-site owlvyhouseacademy-gate

// เมื่อทุกอย่างพร้อม สั่งอัปเดตไฟล์ทั้งหมดขึ้นเน็ต
firebase deploy

2. สรุปปัญหาที่เคยเกิดขึ้นและวิธีแก้ไข (Lessons Learned)

🔴 ปัญหาที่ 1: การติดลูป Login (Login Loop) และ Popup โดนบล็อก

อาการ: นักเรียนกดลิงก์จากแอป LINE หรือ Facebook แล้วกดปุ่มล็อกอิน Google แต่หน้าต่างล็อกอินไม่ยอมเด้งขึ้นมา หรือกรอกข้อมูลแล้วเด้งกลับมาหน้าเดิม

สาเหตุ: In-App Browser ของ LINE/FB มีความเข้มงวดสูง บล็อกการเด้ง Popup แบบ Multi-window และไม่แชร์คุกกี้ข้อมูลร่วมกับเบราว์เซอร์หลักของเครื่อง

วิธีแก้ไขที่เราใช้ (อัปเดตล่าสุด):

  • แก้ที่ Code: เปลี่ยนมาใช้คำสั่ง signInWithPopup() เพื่อให้แสดงผลชัดเจนบนเบราว์เซอร์มาตรฐาน
  • แก้ที่ User Experience: แนะนำผู้ใช้ให้กดจุด 3 จุดมุมขวาบน เพื่อ "เปิดในเบราว์เซอร์เริ่มต้น (Open in Chrome/Safari)" เสมอ
  • แผนสำรอง (Fallback): เตรียมลิงก์ Google Form เพื่อใช้รับข้อมูลแทนระบบล็อกอิน ในกรณีที่เด็กเปิดเว็บไม่ได้จริงๆ

🔴 ปัญหาที่ 2: ชื่อ URL ไม่ตรงกับชื่อแอป (ความงงของ Project vs App)

อาการ: สร้างแอปชื่อ Gemini Gem แต่ได้ลิงก์เว็บเป็น owlvyhouseacademy-gate.web.app

สาเหตุ: Firebase นำชื่อโปรเจกต์ (Project ID) มาทำเป็นลิงก์หลัก ไม่ได้นำชื่อแอปลงทะเบียน (App ID) มาใช้

วิธีแก้ไขที่เราใช้: ใช้ฟีเจอร์ "Add another site" สร้างซับโดเมนใหม่บนโปรเจกต์เดิม และใช้ไฟล์ firebase.json แยกการ Deploy ไฟล์คนละโฟลเดอร์

3. ประเภทการใช้งาน Firebase: Command Line vs Web Console

การทำงานกับ Firebase จะถูกแบ่งหน้าที่อย่างชัดเจนระหว่าง "การจัดการโค้ด" กับ "การจัดการข้อมูล/การตั้งค่า" ดังนี้:

💻 Command Line (Firebase CLI) 🌐 Web (Firebase Console)
หน้าที่หลัก: ใช้จัดการ "ไฟล์โค้ด" ในคอมพิวเตอร์ และส่งงานขึ้นเซิร์ฟเวอร์อินเทอร์เน็ต หน้าที่หลัก: ใช้จัดการ "ข้อมูลฐานข้อมูล", ดูสถิติ และเปิด-ปิดการตั้งค่าระบบความปลอดภัย
คำสั่งที่ใช้บ่อย:
  • firebase login : ลงชื่อเข้าใช้บัญชี Google ในคอม
  • firebase init : เริ่มต้นสร้างโปรเจกต์และสร้างไฟล์ firebase.json ในโฟลเดอร์
  • firebase deploy : (ใช้บ่อยสุด) ส่งไฟล์ HTML/JS อัปเดตขึ้นหน้าเว็บจริง
  • firebase target:apply... : ผูกโฟลเดอร์ย่อยเข้ากับ Site ย่อย
 ฟังก์ชันที่ใช้บ่อย:
  • Firestore Database: เข้าไปดู เพิ่ม ลบ หรือแก้ไขข้อมูลเด็กและคะแนนสอบ
  • Authentication: ดูรายชื่ออีเมลเด็กที่เข้าสู่ระบบมา และตั้งค่า Authorized domains
  • Hosting: กดเพิ่มไซต์ย่อย (Add another site) หรือดูประวัติการ Deploy กดย้อนคืนเวอร์ชันเก่าได้
  • Project Settings: ไปคัดลอกโค้ดตั้งค่า (firebaseConfig) มาแปะในไฟล์ JS
เปรียบเทียบให้เห็นภาพ:
เหมือน "รถบรรทุก" ที่ทำหน้าที่ขนของ (โค้ด) จากโรงเก็บของในบ้านเรา ไปส่งที่โกดังปลายทาง		 เปรียบเทียบให้เห็นภาพ:
เหมือน "ห้องควบคุม (Control Room)" ที่เอาไว้ดูยอดขาย ดูกล้องวงจรปิด และจัดระเบียบโกดัง
