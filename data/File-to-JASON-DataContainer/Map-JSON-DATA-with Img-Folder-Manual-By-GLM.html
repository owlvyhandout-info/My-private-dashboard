ระบบนี้ทำอะไร?

ปัญหาเดิม: สร้างข้อสอบ JSON เสร็จ ต้องหารูปมาจับคู่ทีละข้อด้วยมือ — FlexMapper ทำแทนอัตโนมัติ พร้อมตรวจจับความผิดพลาดให้

  • 📥 วาง ลิงก์โฟลเดอร์รูป + JSON ข้อสอบ ในหน้าเว็บ
  • 🔍 กด Preview → ดูแผนการจับคู่ + คำเตือนทุกจุดเสี่ยง ก่อนแก้ข้อมูลจริง
  • 🚀 กด ประมวลผลจริง → ระบบเติมลิงก์รูปลง JSON ข้อที่เจอ ส่วนข้อที่ไม่เจอคง "" ไว้ + รายงานสาเหตุท้ายโพสต์
  • 📋 คัดลอก JSON ผลลัพธ์ไปใช้ต่อในระบบ

  • 2รหัส [[...]] ใน title เช่น "...กราฟ [[ipst_p3_2558_0017]]" ↔ ไฟล์ ipst_p3_2558_0017.png

GAS มีหลายแบบ — อันนี้คือแบบไหน? (จุดที่งงไปนิด)

มิติทางเลือกที่ระบบนี้ใช้
ประเภทโปรเจกต์Standalone (แยกอิสระ) / Bound (ผูกกับ Sheet, Doc, Form)✔️ Standalone — สร้างจาก script.google.com โดยตรง ไม่ผูกกับอะไร
ประเภทการ DeployWeb App / API Executable / Library / Add-on / Chat App✔️ Web App — ได้ URL หน้าเว็บ (/exec) เปิดใช้งานได้เลย
⚠️ จุดพลาดยอดฮิต: กดปุ่ม ▶ เรียกใช้ (Run) ในหน้าตัวแก้โค้ด = "ทดสอบว่าโค้ดไม่ Error" เท่านั้น ไม่มีหน้าเว็บเด้งขึ้นมา — ต้อง Deploy เป็น Web App แล้วเปิดผ่าน URL /exec เท่านั้น

คลิกหัวข้อเพื่อดูวิธีแก้

▶ กด "เรียกใช้" ในตัวแก้โค้ดแล้วไม่มีหน้าจอให้กรอกอะไรเลย
เป็นพฤติกรรมปกติ — ปุ่ม Run แค่ทดสอบโค้ดฝั่งเซิร์ฟเวอร์ ไม่เปิดหน้าเว็บ
✅ ทางแก้: Deploy → Web app → เปิด URL /exec (ดูแท็บ 🚀 ติดตั้งครั้งแรก ขั้น 6–8) — ถ้า Log ไม่มี Error สีแดง แปลว่าโค้ดพร้อมใช้แล้ว
🖼️ รูปไม่แสดงในหน้าเว็บ / thumbnail เป็นรูปแตก
ไฟล์หรือโฟลเดอร์รูปยังไม่ได้แชร์สาธารณะ
✅ ทางแก้: คลิกขวาโฟลเดอร์รูป → แชร์ → การเข้าถึงทั่วไป → "ผู้ที่มีลิงก์ในไดรฟ์" บทบาท "ผู้ชม"
ทดสอบซ้ำด้วยเครื่องมือ "ทดสอบลิงก์รูปเดี่ยว" ท้ายหน้าเว็บ — รูปต้องขึ้น
❌ Error "รูปแบบ JSON ไม่ถูกต้อง" ตอนวาง JSON
สาเหตุที่พบบ่อย: ใช้เครื่องหมายคำพูดเดี่ยว ' ' แทน " " / มี comma เกินก่อนวงเล็บปิด / JSON ถูกตัดกลางคัน (คัดลอกไม่ครบ) / มีข้อความแปลกปลอมนอก [ ]
✅ ทางแก้: ตัวระบบมี Cleaner ช่วยแก้หลายกรณีอัตโนมัติแล้ว (newline ดิบ, trailing comma, คำพูดโค้ง) — ถ้ายัง Error ให้อ่านตำแหน่งที่ชี้ในข้อความ Error แล้วแก้จุดนั้น หรือสั่ง AI สร้างใหม่ทั้งก้อน
❌ จับคู่ไม่ครบ (ไม่พบรูป > 0)
อ่าน 2 กลุ่มคู่กันเสมอ:
1) ตาราง "ข้อที่จับคู่ไม่สำเร็จ" → ดูเหตุผลของแต่ละข้อ
2) คำเตือน "📁 ไฟล์ที่ไม่ถูกใช้" → ชื่อไฟล์เหล่านี้คือตัวที่ตั้งใจให้จับแต่พิมพ์ผิด
✅ แก้ชื่อไฟล์ใน Drive → Preview ซ้ำจน ❌ = 0 แล้วจึงกดประมวลผลจริง
⚠️ แจ้ง "เลขตรงหลายไฟล์" หรือ "ไฟล์เดียวถูกใช้หลายข้อ"
ชื่อไฟล์ในโฟลเดอร์มีเลขท้ายซ้ำกันหลายไฟล์ (เช่น 1.jpg กับ ข้อ-1.jpg) หรือ id หลายข้อชี้ไฟล์เดียวกัน
✅ ทางแก้: ตั้งชื่อไฟล์ให้เลขท้าย unique ต่อ 1 รูป และยึดหลัก 1 ข้อ = 1 รูป — วิธีที่ดีที่สุดคือตั้งชื่อตาม id2 ทุกไฟล์
🔄 แก้โค้ดแล้วหน้าเว็บไม่เปลี่ยน
หน้าเว็บ Web App ไม่อัปเดตตามโค้ดอัตโนมัติ
✅ ทางแก้: Deploy → จัดการการดีพลอย (Manage deployments) → ✏️ ดินสอ → Version: เวอร์ชันใหม่ → ดีพลอย (URL เดิมใช้ต่อได้)
ช่วงทดสอบเร็ว ๆ: ใช้ URL /dev จาก Test deployments (ต้องล็อกอินบัญชีเจ้าของ)
📤 ข้อไหนไม่มีรูป ระบบทำอะไรกับข้อนั้น?
ตามสเปกที่กำหนด: ข้อที่จับคู่ไม่เจอ ระบบจะคง "image": "" ไว้ (ไม่ลบฟิลด์ทิ้ง) และรายงาน id + id2 + เหตุผลไว้ในกลุ่ม unmatched ท้าย Report — ข้อสอบส่วนที่เหลือยังใช้ได้ปกติ
🗂️ หลายซีรีส์ในโฟลเดอร์เดียว จะจับผิดข้ามซีรีส์ไหม?
ระบบออกแบบให้รองรับแล้ว: ถ้า JSON มี id2 ครบ ระดับ 1 จะจับตรงชื่อไฟล์ ไม่มีทางพลาด ส่วนระดับ 3 (เลขท้าย) มีการกรองด้วย prefix ของ id2 — ถ้าพบไฟล์เลขตรงแต่เป็นคนละซีรีส์ ระบบจะปฏิเสธการจับและรายงานเหตุผล แทนการเดา
