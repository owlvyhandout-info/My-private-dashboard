owlvyhouse-academy.github.io/
  │
  ├── index.html  ← ไฟล์หน้าเว็บหลัก

        ├── tele-bot.png  ← รูปนกฮูก TeleBot
        ├── quiz-bot.png  ← รูปนกฮูก QuizBot
        ├── deep-bot.png  ← รูปนกฮูก DeepBot
        ├── talk-bot.png  ← รูปนกฮูก TalkBot
        └── sim-bot.png   ← รูปนกฮูก SIMBot
⚠️ GitHub ไม่มีปุ่ม "สร้าง Folder" โดยตรง!
ต้องสร้าง Folder โดยการพิมพ์ชื่อ Folder ตอนสร้างไฟล์ใหม่เท่านั้น
1
สร้าง Folder assets/ บน GitHub
  1. 1
    เข้าไปที่ Repository ของคุณ
    https://github.com/owlvyhouse-academy/owlvyhouse-academy.github.io
  2. 2
    กดปุ่ม "Add file" (มุมขวาบน)
    แล้วเลือก "Create new file"
  3. 3
    ในช่อง "Name your file..." ให้พิมพ์:
    assets/  ← พิมพ์ slash ( / ) ต่อท้ายทันที!
    GitHub จะสร้าง Folder assets/ ให้อัตโนมัติ และช่องพิมพ์จะเลื่อนมารอชื่อไฟล์
  4. 4
    พิมพ์ต่อเนื่องจาก assets/ ว่า:
    assets/.gitkeep
    (ไฟล์ .gitkeep = ไฟล์เปล่า ใช้เพื่อให้ GitHub บันทึก Folder ว่างได้)
  5. 5
    เลื่อนลงด้านล่าง → กดปุ่ม "Commit new file" (ปุ่มสีเขียว)
    ✅ Folder assets/ ถูกสร้างแล้ว!
✅ หลังจากนี้จะเห็น Folder assets/ ปรากฏใน Repository แล้วครับ
2
อัปโหลดรูปภาพนกฮูกเข้า Folder assets/
⚠️ ต้องคลิก เข้าไปใน Folder assets/ ก่อน แล้วค่อยอัปโหลด ไม่งั้นรูปจะไปอยู่ Root แทน!
  1. 1
    ใน Repository คลิกที่ Folder assets/ เพื่อเข้าไปข้างใน
  2. 2
    กดปุ่ม "Add file" → เลือก "Upload files"
  3. 3
    ลากไฟล์รูปทั้ง 5 ไฟล์วางในกรอบ หรือกด "choose your files"

    ไฟล์ที่ต้องอัปโหลด (ชื่อต้องตรงเป๊ะ!):
    tele-bot.png
    quiz-bot.png
    deep-bot.png
    talk-bot.png
    sim-bot.png
  4. 4
    เลื่อนลงด้านล่าง
    ช่อง Commit message พิมพ์: Add bot images
    กด "Commit changes" (ปุ่มสีเขียว)
  5. 5
    รอประมาณ 1-2 นาที แล้วตรวจสอบว่าเว็บแสดงรูปถูกต้องหรือยัง
⚠️
ข้อควรระวัง — จุดที่ผิดบ่อยที่สุด!

❌ ความผิดพลาดที่ 1 — ชื่อไฟล์ตัวพิมพ์ผิด

📋 ชื่อไฟล์ที่ถูกและผิด 
✅ ถูก:  tele-bot.png
✅ ถูก:  quiz-bot.png

❌ ผิด:  Tele-Bot.png        ← ตัวพิมพ์ใหญ่
❌ ผิด:  TeleBot.png         ← ไม่มี dash (-)
❌ ผิด:  tele_bot.png        ← underscore (_) แทน dash
❌ ผิด:  telebot.png         ← ไม่มี dash (-)
❌ ผิด:  tele-bot.jpg        ← นามสกุลผิด
❌ ผิด:  tele-bot.PNG        ← นามสกุลตัวพิมพ์ใหญ่

❌ ความผิดพลาดที่ 2 — วางรูปผิด Folder

📋 Path ที่ถูกและผิด 
✅ ถูก:  assets/tele-bot.png     ← อยู่ใน Folder assets/

❌ ผิด:  tele-bot.png            ← วางตรง Root ไม่มี Folder
❌ ผิด:  images/tele-bot.png     ← ชื่อ Folder ผิด (images ≠ assets)
❌ ผิด:  Assets/tele-bot.png     ← A ตัวใหญ่ (Assets ≠ assets)
❌ ผิด:  ./Assets/tele-bot.png   ← A ตัวใหญ่

❌ ความผิดพลาดที่ 3 — ลืมรอ Deploy

⏳ หลัง Commit ทุกครั้ง GitHub Pages ต้องใช้เวลา 1-3 นาที ในการ Deploy
ถ้าเปิดเว็บแล้วยังไม่เห็นรูป ให้รอแล้วกด Ctrl+F5 (Force Refresh) ครับ
📊
ตารางเปรียบเทียบ ถูก vs ผิด
สิ่งที่ตรวจสอบ ✅ ถูกต้อง ❌ ผิด (ตัวอย่าง)
ชื่อ Folder assets Assets / images / img
ชื่อไฟล์ Bot 1 tele-bot.png TeleBot.png / tele_bot.png
ชื่อไฟล์ Bot 2 quiz-bot.png QuizBot.png / quiz_bot.png
ชื่อไฟล์ Bot 3 deep-bot.png DeepBot.png / deep_bot.png
ชื่อไฟล์ Bot 4 talk-bot.png TalkBot.png / talk_bot.png
ชื่อไฟล์ Bot 5 sim-bot.png SimBot.png / sim_bot.png
นามสกุลไฟล์ .png (ตัวพิมพ์เล็ก) .PNG / .jpg / .jpeg
ตำแหน่งไฟล์ อยู่ใน assets/ อยู่ตรง Root หรือ Folder อื่น
