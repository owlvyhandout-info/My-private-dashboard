สภาคำตอบ

ระบบเปรียบเทียบคำตอบจาก AI หลายเจ้า สรุปจุดโต้แย้ง และสร้าง Prompt สำหรับออกแบบสื่อ

ขั้นตอนที่ 1: ตั้งคำถาม
ขั้นตอนที่ 2: วางคำตอบของพยาน
ขั้นตอนที่ 3: ประมวลผลผ่าน AI (ทำตามลำดับ 1 → 2 → 3)
ขั้นที่ 1 [ทำในเว็บนี้]
1. คัดลอก Prompt สำหรับส่งประมวลผล
ระบบจะรวมคำถามและคำตอบจากพยานทุกตัว แปลงเป็น Prompt โครงสร้างพิเศษให้กดคัดลอก
ขั้นที่ 2 [สลับไปหน้าต่างแชท AI]
2. สลับหน้าต่างไปวางใน AI (Gemini / Claude / ChatGPT)
เปิดแชทกับ AI (เช่น หน้าต่างนี้ที่คุณกำลังคุยอยู่) แล้ววาง Prompt ที่คัดลอกมาลงในช่องแชทสั่งงานทันที
เมื่อ AI ตอบกลับมาเป็นชุดโค้ด { JSON } ให้คัดลอกข้อความ JSON นั้นทั้งหมดกลับมา
ขั้นที่ 3 [กลับมาทำในเว็บนี้]
3. วางผลลัพธ์ JSON แล้วกดแสดงผล
นำข้อความ JSON ที่ได้จาก AI ในขั้นที่ 2 มาวางลงในช่องด้านล่าง แล้วกดปุ่มสรุปผลลัพธ์
