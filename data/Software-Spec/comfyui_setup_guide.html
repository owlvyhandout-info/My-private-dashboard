การติดตั้ง ComfyUI (Local)

การติดตั้ง ComfyUI ไว้ใช้งานเองในเครื่อง (Local) เป็นทางเลือกที่ยอดเยี่ยมสำหรับสาย Prompt Engineer เพราะช่วยให้ควบคุม Workflow ได้ละเอียดและไม่มีค่าใช้จ่ายรายเดือนครับ โดยเฉพาะเมื่อคุณต้องการต่อยอดงานด้านสื่อการสอนหรืองาน Character Design อย่างที่ทำอยู่

นี่คือสรุปสเปคเครื่องและขั้นตอนการเตรียมตัวครับ

1. สเปคคอมพิวเตอร์ที่แนะนำ (Hardware Requirements)

หัวใจสำคัญของ ComfyUI คือ การ์ดจอ (GPU) ครับ เพราะ AI ประมวลผลผ่านหน่วยความจำของการ์ดจอเป็นหลัก

อุปกรณ์ ขั้นต่ำ (Minimum) แนะนำ (Recommended)
GPU (NVIDIA) RTX 3060 (VRAM 8GB ขึ้นไป) RTX 3090 / 4080 / 4090 (VRAM 16GB-24GB)
CPU Intel Core i5 / AMD Ryzen 5 Intel Core i7 / AMD Ryzen 7 ขึ้นไป
RAM 16GB 32GB ขึ้นไป
Storage SSD 50GB (พื้นที่ว่าง) NVMe SSD 200GB+ (สำหรับเก็บ Model)
Note: หากใช้การ์ดจอค่าย AMD หรือ Mac (M1/M2/M3) ก็สามารถลงได้ แต่ประสิทธิภาพและขั้นตอนการติดตั้งจะซับซ้อนกว่าฝั่ง NVIDIA (CUDA) ครับ

2. สิ่งที่ต้องติดตั้งก่อน (Software Prerequisites)

ก่อนจะลง ComfyUI คุณต้องเตรียมสภาพแวดล้อมในเครื่องให้พร้อมก่อน ดังนี้ครับ:

  • Python: แนะนำเวอร์ชัน 3.10.x หรือ 3.11.x (ตอนติดตั้งอย่าลืมติ๊กถูกที่ "Add Python to PATH" เด็ดขาด)
  • Git: สำหรับใช้ Clone โปรเจกต์จาก GitHub และใช้อัปเดต ComfyUI ในอนาคต
  • Drivers: อัปเดต NVIDIA Driver ให้เป็นเวอร์ชันล่าสุดเสมอ

3. วิธีการติดตั้ง (Installation Methods)

มี 2 วิธีหลักที่นิยมใช้ครับ:

วิธีที่ 1: แบบ Portable (ง่ายที่สุดสำหรับ Windows)

เหมาะสำหรับผู้เริ่มต้น เพราะรวมทุกอย่างมาให้ในโฟลเดอร์เดียว ไม่ต้องลง Python แยกในระบบ

  1. ไปที่ ComfyUI GitHub Releases
  2. ดาวน์โหลดไฟล์ ComfyUI_windows_portable_nvidia_cu121_or_cpu.7z
  3. แตกไฟล์ไว้ใน Drive ที่ต้องการ (แนะนำ SSD)
  4. กดรันไฟล์ run_nvidia_gpu.bat เพื่อเริ่มใช้งานได้ทันที

วิธีที่ 2: แบบ Manual (สำหรับสาย Dev / Git)

เหมาะสำหรับคนที่ต้องการปรับแต่งหรือใช้ร่วมกับโปรเจกต์อื่น (เช่น n8n หรือ Scripts ต่างๆ)

  1. เปิด Terminal/CMD แล้วพิมพ์:
    git clone https://github.com/comfyanonymous/ComfyUI.git
  2. สร้าง Virtual Environment (แนะนำ) และติดตั้ง Requirements:
    pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121
    pip install -r requirements.txt

4. สิ่งที่ต้องมีหลังจากติดตั้งเสร็จ (Essential Add-ons)

เพื่อให้ ComfyUI ทำงานได้เต็มประสิทธิภาพ คุณควรลงสิ่งเหล่านี้เพิ่มเติมครับ:

  • ComfyUI-Manager: ตัวจัดการ Node และการอัปเดต (ห้ามพลาดเด็ดขาด!)
    ไปที่โฟลเดอร์ custom_nodes แล้วใช้คำสั่ง:
    git clone https://github.com/ltdrdata/ComfyUI-Manager.git
  • Checkpoint Models: ไปโหลดไฟล์ Model (เช่น SDXL, Pony, หรือ Realism ต่างๆ) จาก Civitai มาวางไว้ในโฟลเดอร์ models/checkpoints
