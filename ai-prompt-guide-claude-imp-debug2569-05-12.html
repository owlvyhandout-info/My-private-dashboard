# AI Code Review — Careful Mode

Before making any changes:
1. Read the ENTIRE file first — do not skip or truncate
2. Identify the root cause, not just the symptom
3. List exactly which lines you will change and why
4. Make minimal changes only — do not touch unrelated code
5. After editing, verify the change is consistent with the rest of the codebase
6. If unsure, ask once before acting — do not guess and fix repeatedly

Think step by step before writing any code.
The full file is provided — do not assume missing content.
Show only the changed lines with line numbers, not the full file.

# โหมดรอบคอบ — ก่อนแก้โค้ดทุกครั้ง

ก่อนแก้โค้ดทุกครั้ง:
1. อ่านไฟล์ทั้งหมดก่อน — ห้ามข้ามหรือสรุปเอง
2. หาสาเหตุที่แท้จริง — ไม่ใช่แค่แก้อาการ
3. บอกว่าจะแก้บรรทัดไหน และทำไม
4. แก้เฉพาะจุดที่จำเป็น — ห้ามแตะโค้ดที่ไม่เกี่ยว
5. หลังแก้ ตรวจสอบว่าไม่ขัดแย้งกับโค้ดส่วนอื่น
6. ถ้าไม่แน่ใจ ถามก่อน 1 ครั้ง — อย่าเดาแล้วแก้ซ้ำ

คิดทีละขั้นตอนก่อนเขียนโค้ดทุกครั้ง

แสดงเฉพาะบรรทัดที่แก้พร้อมเลขบรรทัด — ไม่ต้องแสดงทั้งไฟล์

Checklist ก่อนส่งโค้ดให้ AI แก้
01
ส่งไฟล์ทั้งหมด ไม่ใช่แค่บางส่วน
ถ้า copy แค่บางส่วน AI จะเดาส่วนที่หายและอาจแก้ผิดบริบท
02
บอก error message หรืออาการที่เจอให้ชัดเจน
เช่น "กดปุ่ม Export แล้วไม่มีอะไรเกิดขึ้น" ดีกว่า "Export ไม่ได้"
03
ระบุว่าแก้แล้วต้องการ output แบบไหน
เช่น แสดงเฉพาะบรรทัดที่แก้ หรือ ส่งไฟล์ทั้งหมด
04
บอก context ของ stack ที่ใช้
เช่น ใช้ vanilla JS, localStorage, GitHub Pages — ไม่มี backend
05
ถ้า AI แก้ผิด ให้บอกตรงๆ ว่าผิดอะไร
อย่า paste error แล้วให้เดาเอง — ระบุให้ชัดว่าจุดไหนยังพัง
